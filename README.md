# hexagram · 观象

个人学习站集合，**配置驱动的分站平台 + 分组隔离**：十组——易道（易经研习 + 道藏研读，门户互切）／ 儒 ／ 佛 ／ 心（阳明心学）／ 法家 ／ 墨家 ／ 兵家 ／ 纵横家 ／ 中医 ／ 谋略杂纂，各组两两零可见链接；左上角 logo 链向总门户（九…十组总入口）。

- **易经研习**（默认，朱砂主题）——六十四卦原文与十翼通读、64 卦白话全译、经文字词注释与经传逐段注疏（悬停出注）、卦主标注、确定性卦变推演（变/互/错/综、变占规则、爻位分析）、八宫纳甲、推演六法（梅花引导/大衍/金钱卦等）＋验占回填、学堂教程与练习（含六十四卦认读闪卡）、易学源流与人物志、春秋筮例（左传/国语 21 条占筮引易实录，卦例可一键在工作台重演）、爻辞商周史事、先天方圆图、全站搜索（卦/经传/名词/筮例/史事/人物）、今日一卦、研习进度。
- **道藏研读**（玄青主题）——六部经典全文阅读器：道德经、清静经、太上感应篇、庄子内篇、阴符经、周易参同契；白话全译 562 段、锚定字词注疏（生僻注音/通假/名物/丹道隐语）、撰人小传、每章末「延伸」（思想/故事/源流，六部 128 章全覆盖）；短经单页铺排；参同契/阴符经注疏内卦名单向跳转易经卦页（「桥」，易经侧零反向链接）。
- **儒典研读**（苍绿主题）——四书 + 孝经：论语、孟子、大学、中庸、孝经（今文 18 章）；白话全译 1319 段、锚定字词注疏、篇/卷级延伸；主流参照朱熹《四书章句集注》。
- **释典研读**（缁黄主题）——四经：心经（玄奘略本）、金刚经（罗什本 32 分）、坛经（宗宝本 10 品）、四十二章经（高丽藏古本）；白话全译、梵汉对音名相注疏、章级延伸；守「研习不宣化、不下吉凶/果报断语」。
- **阳明心学**（靛紫主题）——《传习录》三卷：心即理、知行合一、致良知；967 段全译、锚定字词注疏、卷级延伸（思想史视角）。
- **诸子百家**（法家·墨家·兵家·纵横家，四个独立平级模块，各自一组）——法家（韩非子·商君书）／墨家（墨子核心）／兵家（孙子·吴子·司马法·尉缭子·三略）／纵横家（鬼谷子·战国策选十八篇）；十书全译注延：白话全译约 1840 段、锚定字词注疏约 5400 条、篇级延伸 201 篇；取思想史与文献视角，不作政治影射、不作权术教程。全站读经类站均可全文检索（搜经名/译文/注疏/延伸，分组隔离）。
- **中医典籍**（杏林赭主题）——黄帝内经·素问（选 15 篇）／灵枢（选 8 篇）／伤寒论（22 篇）／神农本草经（365 药）；约 2211 段全译、锚定字词注疏、篇级延伸；取医学史与文献视角。**铁律「研习不诊疗」**：经文照译，注疏/延伸不述方药功效用法、不下病症/疗效断语，全站「⚠ 非医疗建议」声明。
- **谋略杂纂**（黯灰紫主题）——《天下无谋·秘卷八书》维基有原文的 5 部：罗织经／小人经（荣枯鉴）／权谋术／韬晦术／止学；约 1.1 万字全译、字词注疏、篇级延伸。⚠ **这些托名古人的书学界多判为后世托名或现代伪作**——书架与题解显著标「托名·疑现代伪作」，作伪书现象与世态心理的文献材料研读，取文献批判视角，**不作处世权术教程**。

前端为 React 19 + Vite，经文数据构建期生成，个人研习数据仍存 localStorage（可导出导入）；Cloudflare Pages Functions（Hono）+ D1 目前只承载匿名阅读统计，接口不可用时不影响阅读。支持静态/PWA 资源托管与首访后离线阅读。

## 快速开始

```bash
npm install
npm run dev
```

## 常用命令

```bash
npm run dev            # 开发服务器
npm run build          # 生产构建
npm test               # vitest(推演引擎单测)
npm run data:fetch     # 易经管线:维基文库《周易》抓取生成
npm run data:fetch-dao # 道藏管线:六部经典抓取生成
npm run check-data     # 数据校验(结构/繁简哨兵/译注覆盖/注疏锚点),数据变更后必须通过
```
