# 典籍目录页美化方案(每本书一页的那一屏)

> owner 2026-10-07:「每本典籍的目录页想办法美化一下……加入交互类的内容,或者跟这本书相关的图片;图片不要自己生成,
> 在本地调 Codex CLI 的出图工具;每本书要按它的历史背景和上下文做判断。先写方案,看过再做。」
> **本稿只是方案,未开工。** 文末 §7 是等你圈的问题,回编号 + 选项即可。

## 0 · 一句话

把现在「题解 + 小传 + 一片平铺的章号格」的目录页,改成「**一幅这本书的象 + 一条这本书的结构 + 几个能动的入口**」:
每本书一幅单色白描插图(Codex 出图、随三套主题自动变色)、目录按这本书自己的结构分段(道经/德经、六韬六篇、战国策按国……)、
一排「透镜」按关键词点亮章格,外加把散在各处的名句 / 人物 / 时间轴 / 争鸣入口收成一行。
**易经不在本轮**(它有自己的一套页面),观书 `/books` 的生成式书封也不动。

## 1 · 现在的页面,问题在哪(以道德经截图为准)

## 3 · 插图:怎么出、什么风格、放哪儿

### 3.1 风格(三套主题都要成立)
- **单色白描 / 减笔水墨,透明底,不含任何文字、印章、边框、人脸。** 出图时要求透明背景;落地后**不当 `<img>` 用,当 CSS `mask-image` 用**,填色走 `var(--ink-soft)`(或组色 accent 的淡化)——
  这样观火(宣纸)/ 观素(白)/ 观水(暗)三套主题下插图自动是对的颜色,不会出现暗色主题里一块白底图。墨色浓淡保留在 alpha 里,所以减笔水墨的层次也在。
- 母题一律**物象、景象、典故场景**,不画人物正脸(生成的脸不可信,老子孔子像也都是后人想象);佛组不画佛像(研习不宣化);道组不画神像;中医不画诊疗、不画人体穴位图;伪书五部的母题要和「托名」的身份相称,不给它们画得气派。
- 构图:方形 1024²,主体偏一侧、大面积留白(题头右侧只有 160–220px,留白才不挤)。

### 3.2 出图链路(全部走 Codex CLI,我不自己画)
- 本机 `codex` 0.160,`image_generation` 已启用(模型 gpt-image-2)。**已试出一张**(青牛向关,见 §3.5 结果行)。
- 写一份 `scripts/authored/book-art.json`:每本书 `{slug, motif, prompt, alt, note}`——**prompt 我逐本手写**(母题见 §5 表),alt 给屏幕阅读器。
- `scripts/gen-book-art.mjs`:逐本调 `codex exec -C <临时目录> "<prompt>"`,取回 PNG → 裁掉空白边、补成方形、只留 alpha 通道压成单通道 PNG(当遮罩用,800²、≤ 150 KB) → 落到 `public/book-art/<组>/<slug>.png`。只补缺的,改 prompt 后 `--force <slug>` 重出。
- 每本出 2 张候选,我挑一张;挑不出的重写 prompt 再出。**人眼过一遍是必须的**:生成图常见毛病是夹带假汉字、多出一只手、构图太满。
- 不进 PWA 预缓存(`globPatterns` 不含 png,现状即如此),`loading="lazy"`;`_headers` 给 `/book-art/*` 加长缓存。

### 3.3 数量与成本
约 **88 本**(dao 15 · ru 9 · fo 10 · xin 2 · fa 4 · mo 1 · bing 7 · zong 2 · zhongyi 6 · moulue 9 · mingli 9 · guwen 2 · 诗词曲 4,易经不算),每本 2 候选 ≈ 180 次出图。
走的是你的 Codex 额度,不占 Claude token;时间上批跑一晚上够。

### 3.4 校验(进 check-data)
每本书要么有图要么在 book-art.json 里显式 `none`;文件存在、方形、≤150 KB、带 alpha 通道;alt 非空。图不对不会让构建失败,但会列在覆盖仪表里。

### 3.5 试出结果(2026-10-07,一次 `codex exec`,Codex 侧约 1.6 万 token)
- 提示词「单色白描,老者骑牛背影向关隘,留白,透明底,无字无印无框」→ 回来一张 1254² RGBA PNG:**77.5% 像素全透明、其余全是半透明墨色**,
  也就是真透明底、墨色浓淡在 alpha 里,正是 §3.1 要的形态。
- 只取 alpha 通道缩到 1024² 存成单通道 PNG = 191 KB;按 §3.1 用作遮罩,分别染观火的 `--ink-soft` 铺在宣纸底、染淡墨铺在观水的暗底,两张合成图见随方案发你的 `demo-both.jpg`——
  **同一个文件,浅色暗色都对**。落地尺寸定 **800²、≤ 150 KB**(题头位只有 160–220px 宽,800 足够 2× 屏)。
- 这一张的毛病:构图偏满,牛和人占了下半幅,放题头右侧会挤;正式 prompt 要写死「主体占画面三分之一、偏一侧、上方大片留白」。
  人物背影可接受(没有脸),但 §3.1 的原则不变:默认画物象 / 景象,人物只在典故场景里当背影、远景。

## 4 · 交互件:新做三样通用的,道德经另加一样

| 件 | 做什么 | 数据从哪来 / 怎么验 | 量级 |
|---|---|---|---|
