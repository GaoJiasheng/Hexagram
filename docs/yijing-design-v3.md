## 3. 金钱卦(占法 II)

### 3.1 规则表(唯一依据)

三枚铜钱同掷为一次,得一爻;六掷成卦,**自下而上**(第一掷为初爻)。有字一面为「字」,无字一面为「背」。**背计 3,字计 2**,三枚之和定爻:

| 组合 | 和 | 爻值 | 名称 | 阴阳 | 动否 |
|---|---|---|---|---|---|
| 三背 | 9 | 9 | 老阳(重) | 阳 ○ | 动 |
| 两背一字 | 8 | 8 | 少阴(拆) | 阴 | 静 |
| 一背两字 | 7 | 7 | 少阳(单) | 阳 | 静 |
| 三字 | 6 | 6 | 老阴(交) | 阴 ✕ | 动 |

爻值体系与大衍揲蓍完全一致(6/7/8/9;7、9 为阳爻,6、9 为动爻),binary 与动爻的换算复用同一逻辑。

### 3.2 引擎 `engine/jinqian.js`(纯函数,rng 注入)

```
tossCoins(rng)        → [b,b,b]  每枚 rng()<0.5 为背(1),否则字(0)
valueFromBacks(backs) → 6 + backs           // 0背→6 … 3背→9
tossLine(rng)         → { coins, backs, value }
tossHexagram(rng)     → { lines:[{coins,backs,value}×6], values, binary, movingLines }
COIN_LABELS           → { 6:'三字 · 老阴 ✕', 7:'一背两字 · 少阳', 8:'两背一字 · 少阴', 9:'三背 · 老阳 ○' }
```

自检用例(必须入单测):valueFromBacks 全映射;全背 rng→9、全字 rng→6;binary 位与 values 一致(7/9→'1');movingLines 为 6/9 的 1 起位序;makeSeededRng 同种子两次结果一致。

### 3.3 工作台「金钱」标签

三个子入口(seg 切换):

- **一键**:tossHexagram(cryptoRng) 一次出六爻,列表展示每掷组合与爻值,按钮「入卦 →」。
- **逐掷(引导)**:一次掷一爻,显示三枚铜钱字/背、求和算式、爻名;首掷附一句规则说明;右侧爻柱自下而上累积;六掷后「入卦 →」。
- **录入**:六行(初→上),每行四选(三背○动 / 两背一字 / 一背两字 / 三字✕动),全选后「入卦 →」。供用户掷实物铜钱后录入。

入卦统一走 `onQiGua(hex, movingLines, { method:'jinqian', inputs:{ values } })`。

### 3.4 教学页 `/basics/jinqian`

节次:①何为金钱卦(汉代火珠林一脉,最通行的简易起卦法);②取数表(§3.1 原表);③六掷成卦流程(自下而上、动爻将变);④与大衍的关系(爻值体系相同,繁简之别);⑤练一练;⑥CTA。

## 4. 梅花引导模式

### 4.1 原则

MeihuaPanel 内加 [快速|引导] 开关,默认快速(现状不变)。引导为分步向导,**所有数字用当前输入实时演算**,规则出处《梅花易数》。先天卦数速查表组件 XianTianTable(乾1兑2离3震4巽5坎6艮7坤8,高亮当前余数)在引导与教学页共用。

### 4.2 逐步文案表

时间起卦五步:

| 步 | 标题 | 内容要点 |
|---|---|---|
| 1 | 取数 | 年支序数(子1…亥12)、农历月、日、时支序数;农历自动换算可手改 |
| 2 | 求上卦 | 年支+月+日=和;÷8 取余(**余0取8**);余数对先天卦数表得上卦 |
| 3 | 求下卦 | 前和+时支=总和;÷8 取余同法得下卦 |
| 4 | 定动爻 | 总和 ÷6 取余(余0取6),得动爻位;动爻所在之卦为「用」,另一卦为「体」 |
| 5 | 成卦 | 预览本卦+动爻;按「起卦 →」入工作台,体用卡自动出现 |

数字起卦四步:①两数来源(报数/笔画/所感之数);②数一÷8→上卦;③数二÷8→下卦,两数和÷6→动爻;④成卦。

例(观梅典故,与 meihua.test.js 一致):辰年(5)十二月十七日申时(9):5+12+17=34,÷8余2→兑上;34+9=43,÷8余3→离下;43÷6余1→初爻动。泽火革之咸。

### 4.3 教学页 `/basics/meihua`

节次:①何为梅花易数(邵雍,观物起数);②先天卦数表;③时间起卦(§4.2 表 + 观梅例);④数字起卦;⑤体用断法(动者为用、静者为体;五行生克五型:用生体吉/比和吉/体克用小吉/体生用耗/用克体凶——文案沿用 engine/meihua.js 既有断语);⑥练一练;⑦CTA。

## 6. 练习层

## 7. 贯通机制

### 7.1 双向跳转映射

| 工作台方法 | 「学这个方法」目标 | 教学页 CTA 目标 |
|---|---|---|
| trigram / line | /basics/yinyang | /workbench?method=trigram |
| meihua | /basics/meihua | /workbench?method=meihua |
| dayan | /basics/shicao | /workbench?method=dayan |
| jinqian | /basics/jinqian | /workbench?method=jinqian |

workbench 读 `?method=` 参数做初始方法预选(非法值落回 trigram);现有 gua/dong 参数行为不变。河洛页加一句互链:「这套数字是梅花取数的依据 → 梅花易数」。

### 7.2 术语补丁(工作台)

体用卡标题、贞悔分析句、大衍/金钱面板的「动爻」「老阳」等首现术语用既有 TermTip 包裹(glossary 已有 tiyong/zhenhui/dongyao/dayan 等词条)。链接元素(deriv-chip 等)内**不**嵌 TermTip,避免点击冲突。

### 7.3 进度存储

`guanxiang.v1.progress`,经 storage.js 封装:

```json
{ "read": { "yinyang": "ISO时间" },
  "quiz": { "yinyang": { "passed": true, "best": 4, "total": 4, "at": "ISO" } },
  "used": { "meihua-time": "ISO", "dayan": "ISO", "jinqian": "ISO" } }
```

- markRead(topic):教学页挂载时写(七篇含 glossary)。
- markQuizResult(topic, correct, total):QuizCard 交卷时写;passed 只升不降,best 取历史最高。
- markMethodUsed(key):工作台 onQiGua 成功时写(meihua-time / meihua-number / dayan / jinqian)。
- exportData / importData / clearAllData 的键列表加入 'progress'。

### 7.4 主题注册表与进度展示

LEARN_TOPICS(七项)定义于 BasicsPage 并导出,「我的·研习」复用:yinyang、hetu-luoshu、xiaoxi(读+练);shicao→dayan、meihua(used 取 meihua-time 或 meihua-number)、jinqian(读+练+用);glossary(仅读)。学堂目录卡右侧三个小点 读/练/用(灰=未,朱=完成;无该层则不显示);「我的」新增「研习」标签,列表展示同样状态并链到各页。

## 8. 明确不做与后置

- 不做六爻装卦断卦(纳甲/六亲/世应已在 M5 详情页,占断不做)。
- 不做练习题随机生成、计时、错题本;题库静态够用。
- 不做引导模式动画/音效;铜钱与蓍草均为静态字符呈现。
- 进度不上云、不加成就系统。

## 9. 里程碑与验收

- **P0 贯通**:六法标签 + method 参数;「学这个方法」四处;教学页 CTA;术语补丁。验收:从任一教学页一键到达对应方法;从工作台任一方法一键到达对应教学页。
- **P1 梅花**:引导五步/四步向导(实时演算+先天表高亮);/basics/meihua 上线含观梅例。验收:观梅例按 §4.2 走通;快速模式行为与现状逐项一致。
- **P2 大衍**:DayanCast 抽取,ShicaoPage 行为不变;工作台大衍标签一键+引导。验收:演示种子 42 步进结果与改造前一致;一键成卦动爻正确入卦。
- **P3 金钱**:引擎+单测全过;三入口;/basics/jinqian。验收:§3.2 自检用例全绿;录入「三背×6」得乾之坤六爻皆动。
- **P4 练习**:QuizCard + 六主题题库;各教学页嵌入。验收:全对写 passed,错题显示解释。
- **P5 进度**:storage progress;学堂目录路径化;「我的·研习」。验收:读/练/用三类动作各自点亮;导出含 progress。
