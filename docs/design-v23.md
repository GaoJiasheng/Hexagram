## §0 定位与铁律

**这是一个能把命理典籍真正读进去的地方,不是算命网站。**主角是书——《渊海子平》《子平真诠》《滴天髓阐微》《穷通宝鉴》,
其后《三命通会》与源头诸书;交互件与学堂是**为读书服务的门**。

### 铁律:研习不断命(第十五组,与中医「研习不诊疗」同构)

1. **原典断语照译。**这些书通篇是断语(「此造必贵」「早年刑克」),处理办法同《本草经》的「主治」:不删不讳,不加强也不软化。
2. **注疏、延伸、白话、学堂不背书。**只作字词训诂、术语解释与学说史;不评判命例中人的吉凶,不补充原文没有的断语;
   **绝不教读者拿去给自己或他人断命**,不出现「你可据此判断自己……」式的套用指引。
3. **工具止于结构。**一切交互件与排盘台只输出符号结构(四柱、藏干、十神、五行分布、大运排列),
   **不输出任何吉凶、性格、运势判断**。`analyzePillars` 与 `daYun` 的输出有单测断言不含断语用字。
4. **分歧如实,不替用户拍板**(§4)。真伪与底本如实(§7)。
5. **版权**:只收作者卒于清代或更早之书;**不收**任何 20 世纪评注(徐乐吾、韦千里、袁树珊等)。`check-data` 有闸(§8)。

## §2 引擎分层(`src/features/shared/ganzhi/`)

观数、中医五行藏象、易经纳甲、参同契月体纳甲踩在同一套符号上,故为**共享底座**,不放在 `features/mingli/` 下。

| 层 | 文件 | 做法 | 理由 |
|---|---|---|---|
| **规则层** | `index.js` | 纯函数、零依赖、同步;全是查表与模运算 | 学堂要把规则**讲给人看**,它们必须是我们能解释的数据,不能是库里的黑盒 |
| **历法层** | `calendar.js` | async,懒加载 `lunar-javascript`(~426KB,只在此模块内) | 节气交接是天文计算,不能手写。已知四柱的场景(书中命例)**完全不用加载** |

**oracle 交叉验证**(`ganzhi.test.js`):1500 个确定性伪随机时刻,自写规则层的月干 / 时干 / 十神 / 藏干 / 纳音 / 十二长生
与 `lunar-javascript` 的 `EightChar` **逐项全等**。两个独立来源对得上才算数(同「64 卦基准表与抓取内容互相校验」)。

**严禁凭记忆补规则。**下表每条规则的出处均已在站内底本中查实(2026-09-19);引文取原文,个别字形从底本。

| 规则 | 内容 | 出处 |

| 以日为主 | 日干为「我」,其余七字从它看出去 | 《渊海子平》:「以日为主,年为本,月为提纲」;《三命通会·论年月日时》:「遁月从年,则以年为本,遁时从日,则以日为主」 |
| 五行相克之制化 | 克不克得动看力量对比 | 《渊海子平》:「金能剋木,木坚金缺;木能剋土,土重木折;土能剋水,水多土流;水能剋火,火多水热;火能剋金,金多火熄」 |

| **五鼠遁**(日上起时) | 子时之干 = (日干序 mod 5) × 2 | 同篇古歌:「甲己还加甲,乙庚丙作初,丙辛从戊起,丁壬庚子居,戊癸何方发?壬子是直途」 |
| 遁干何以只五种 | 起法相同的两干恰为天干五合之两干 | 同篇:「月时之法,取天干合数,阴阳之配也」 |

| 七杀之名 | 隔七位相克 | 《三命通会·论冲击》:「地支取七位为冲,犹天干取七位为煞之义。如子午对冲,子至午七数,甲逢庚为煞,甲至庚七数」 |

| 地支六合 | 子丑、寅亥、卯戌、辰酉、巳申、午未 | 《三命通会·论支元六合》:「子合丑,寅合亥……」 |

| 三刑 | 子卯无礼、寅巳申无恩、丑戌未恃势;辰午酉亥自刑 | 《三命通会·论三刑》 |

## §5 `widget` 块 —— 富文本里「活的块」

```json
{ "type": "widget", "kind": "sizhu", "props": { "pillars": ["辛卯","丁酉","庚午","丙子"], "focus": ["丁","午"] }, "caption": "……" }
```

与静态 `figure`(内联 SVG)并存。区别:**管线只写参数、不画图** —— 省 token、风格统一、明暗自适应,
且**参数错了机器查得出**(死 SVG 画错了谁也查不出)。白话 / 观书 / 导读 / 学堂共用 `BaihuaArticle` 渲染器,加一种块四处生效。旧图不动。

| 文件 | 职责 |
|---|---|
| `shared/widgets/schema.js` | 各 kind 的 props 校验。纯 JS,**浏览器与 `check-data` 共用同一份** |
| `shared/widgets/WidgetBlock.jsx` | 宿主:按 kind 懒加载;参数不合法 / 件抛错 / kind 未实现 → 只留 caption,**不连坐整篇文章** |
| `shared/widgets/<Kind>.jsx` + `.css` | 各件。样式随件懒加载,不进首屏 CSS |

**加一个件三步**:`schema.js` 登记校验 → `WidgetBlock.jsx` 登记懒加载 → 本节补契约。

### 件的总则

每个件只有一条验收标准:**「读者动什么 → 悟什么」在页面上真的成立。**讲推导过程,不只给结论;不输出断语;
明暗两套;320px 不横向溢出(矩阵除外);键盘可操作;规则一律调 `ganzhi`,**件内不许手写规则表**。

### props 契约(v1,八件)

| kind | props | 动什么 → 悟什么 |
|---|---|---|
| `sizhu` 四柱图 | `pillars`(必填,4 干支)· `focus?`(高亮的干/支字)· `show?`(`shishen/canggan/nayin/changsheng/count`) | 点任何一个字 → 它是什么、十神怎么推出来的。**让人看懂书里的命例** |
| `wuxing` 五行图 | `center?` · `highlight?` · `labels?`(每行挂标签,中医用)· `mode?`(`sheng/ke/both`) | 点一行 → 四向关系。相生是相邻、相克是隔一 |
| `jiazi` 六十甲子 | `highlight?` | 走一遍 → 永远沿斜线,一半格子踩不到。为什么是 60 不是 120 |
| `shishen` 十神盘 | `dayGan?` | **换日主 → 全盘重标**。十神是关系不是属性 |
| `dizhi` 十二支盘 | `show?`(`liuhe/sanhe/sanhui/chong/xing/hai`)· `focus?` | 开关连线 → 冲是对径、三合是正三角、六合是一组平行弦 |
| `qizhu` 起柱演示 | `which?`(`month/hour`)· `gan?` | 选年干 → 十二月干自动排出。口诀只是取余,十干只有五种起法 |
| `jieqi` 节气年轮 | `year?` | 拖日期 → 年柱在立春那一刻变,不在元旦、不在春节 |
| `matrix` 可点矩阵 | `rows` · `cols` · `cells{'行\|列':{text,href?,note?}}` · `rowLabel?` · `colLabel?` | 一眼看全局,点格下钻。通用件(穷通 10×12、本草 6×3……) |

后续件(各自立项时补契约):`tree` 判定流程图 · `stepper` 案例步进走读 · `timeline` · `graph` · `lens` 视角切换。

## §6 学堂六篇(`src/data/mingli/learn/<key>.json`)

定位:**读这些书之前必须会的六件事。**格局、旺衰、调候、大运**不进学堂**——那是书里讲的,让书来讲。

正文是**数据不是组件**:与白话同一个块模型(`lead/h2/p/list/callout/table/pull/steps/widget`)+ `quiz[]`,
由 `BaihuaArticle` 渲染、`QuizCard`(已泛化,接受外部题库;进度键 `mingli:<key>`)出题。

| # | key | 题 | 核心件 | 要破的那个误解 |
|---|---|---|---|---|
| 1 | `jiazi` | 六十甲子 | `jiazi` | 干支不是暗语,是编号;为什么只有六十种 |
| 2 | `jieqi` | 节气与年月 | `jieqi` | 「过了春节才换属相」在八字里不成立 |
| 3 | `wuxing` | 五行生克 | `wuxing` | 五行不是五种元素;从「我」看出去只有五种关系 |
| 4 | `qizhu` | 四柱怎么排 | `qizhu` ×2 | 口诀不是咒语,是取余 |
| 5 | `shishen` | 十神 | `shishen` + `sizhu` | 「丙是食神」这种话不成立——十神相对日主而言 |
| 6 | `dizhi` | 地支藏干与合冲刑 | `dizhi` + `sizhu` | 通根、透干是什么;关系写在几何里。**只讲结构,「合了会怎样」留给书** |

文中凡日期、干支、十神等**可计算的断言,一律用引擎算过再写**(2024 立春 2/4 16:27 早于春节 2/10;2025 春节 1/29 早于立春 2/3 22:10)。

## §8 `check-data` 新增

1. **widget 块**:白话 / 学堂 / 导读里的 `widget` 块过 `validateWidget`,不合法即 error
2. **学堂**:六篇齐全、块型合法、`quiz` 每题 `answer` 在选项范围内
3. **版权闸**:`mingli` 组全部原文扫现代评注痕迹词表(徐乐吾 / 韦千里 / 袁树珊 / 民国 / 总统 / 督军 / 时人姓名 / 科学 / 西历……),命中即 error
4. **矩阵数据**:每格引文须为该书该章原文精确子串(同争鸣 cite 校验)
5. **红线软扫**:白话 / 延伸 / 注疏里出现「你的命」「可据此判断」「预测」等套用指引用语 → warn,人工复核
