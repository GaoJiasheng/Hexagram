# 诗词曲三组作业标准(唐诗 / 宋词 / 元曲)

> **这是唯一作业标准。** 换任何一个 session 接手,照此做就能产出同一质量的内容;
> 不照此做的产出一律不收。待办进度记在 [todo.md](./todo.md),不记在本文。
>
> 建立于 2026-08-03(框架期,原文已抓、译注/白话/导读未做)。

---

## 0. 先认清:这三组和站内其余十一组不一样

| | 其余十一组 | 诗词曲三组 |
|---|---|---|
| 部类 | 经、子 | **集**(文学) |
| 读法 | 求义理 | **求意象与声情** |
| 一章 | 一篇文章/一段论说 | **一首诗词曲**(极短,四句到数十句) |
| 危险 | 曲解义理、越界宣化 | **把诗读成格言、把词读成鸡汤** |

**最容易犯的错**:给一首诗写「人生启示」。诗不是用来提炼道理的 ——
杜甫写「感时花溅泪」不是要教人惜时,李煜写「一江春水向东流」不是要论无常。
把诗词曲降格成心灵鸡汤,是这一层最坏的失败,比译错一个字严重得多。

**唐诗/宋词的选目是古人定的**,我们只照抄;
**元曲的选目是本站定的**,必须在 texts.json 的 `caveat` 与书架 `disclaimer` 里显著标明 ——
这条不能省,省了就是把自己的编纂冒充古人的选本。

### 篇目从哪来:不手打

```bash
node scripts/gen-poetry-lists.mjs      # 从维基文库推导 → scripts/corpus/_poetry-lists.json
node scripts/fetch-corpus.mjs tangshi  # 唐诗
node scripts/fetch-corpus.mjs songci   # 宋词
node scripts/fetch-corpus.mjs yuanqu   # 元曲
```

`_poetry-lists.json` **不许手改**。底本页若变动,重跑后的 diff 会把变化显出来 —— 这是刻意的。

### 元曲加曲目:唯一正确做法

1. `_poetry-lists.json` 的 `yuanqu.authors` 是 354 首**候选池**——**但池子不全**
   (张养浩、乔吉、徐再思、贯云石不在内,张可久只收 1 首)。想收的多半不在池里。
2. **先探测页面是否存在**,再写进 `scripts/corpus/yuanqu.config.mjs`:
   ```bash
   node -e "fetch('https://zh.wikisource.org/w/api.php?action=query&format=json&formatversion=2&titles='+encodeURIComponent('页名')).then(r=>r.json()).then(j=>console.log(j.query.pages[0]))"
   ```
3. **页名照抄探测结果,一个字不改**。标题体例极不统一:繁简混用(「人月圆·山中书事」是简体页名)、
   `·` 与半角空格混用(《山坡羊 潼關懷古》)、括号消歧(《憑闌人 (張可久)》)。
   凭印象写必然抓空 —— 24 个候选里 12 个因标题形式不符而「不存在」。
4. **当心转写壳**:《山坡羊 (張養浩)》整页只有 `{{:子页}}`,自身无正文,抓下来 0 段。
   正文在 `山坡羊 潼關懷古` / `山坡羊 驪山懷古` 两个子页。(同款坑见 CLAUDE.md 黄庭经「全覽」)
5. **查无原文者一律不收**。睢景臣《般涉调·哨遍·高祖还乡》整个维基文库都没有 —— 那就不收。
   ⛔ **严禁凭记忆补曲文。**

## 2. 译注(第一层)

一首诗一组译注,含**白话直译**与**字词注疏**两部分,与站内其余各组同构。

### 白话直译

- **一句对一句**,不重组、不合并、不添意。原文四句,译文四句。
- **保留意象,不作解释**。「感时花溅泪」译作「感伤时局,看花也落泪」,
  **不要**译成「因为忧国忧民,连看到美丽的花朵都忍不住流泪,表达了诗人深沉的爱国情怀」——
  后半截是解读,属延伸层,不是译文。
- 典故在译文里**照直译出**,考释放注疏。「庄生晓梦迷蝴蝶」译「庄周清晨梦中化为蝴蝶」,
  别在译文里塞「用《庄子·齐物论》典」。
- 歧解取通行说,分歧写进注疏,**不在译文里骑墙**。

### 字词注疏

- 只注**读不懂的**:僻字、通假、专名、典故、名物、格律术语。
- **不注情感、不注主旨**——那是延伸层的事。
- 每条 ≤40 字,`term` 必须是**原文精确子串**(装配时会逐条校,不中即弃)。
- **词牌/曲牌不是题目**。《木兰花》不写木兰花、《天净沙》不写沙,
  这是**格律调名**;凡词曲首见其调,注疏须点明「调名,与内容无关」——
  这是初学者最常见的误解,漏注等于放任误读。

## 3. 每首延伸(第二层)

一首一则,讲**这首为什么值得读**。

**可以写**:创作本事(须分清史实与传说)、意象源流(「杨柳」何以关送别)、
声律安排(拗救、平仄如何造成顿挫)、后世化用、同题异作对读。

**不可以写**:
- ❌ **人生启示 / 处世哲理 / 励志发挥** —— 这一层最大的红线
- ❌ 把作者生平当成诗意的唯一解(「因为他被贬了所以这句是牢骚」)
- ❌ 现实影射(把边塞诗读成当代国际关系)
- ❌ 把传说当史实(《长恨歌》的本事、李白的传说,须标明「相传」)

**分级照站内既定四级**(见 design-v9 §4):共识直写 / 考证标出处 / 存疑明示 / 宁缺毋滥。

## 4. 白话深读(第三层)

粒度**三组不同**,写之前先看清楚:

| | 粒度 | 章键形态 | 依据 |
|---|---|---|---|
| **唐诗** | **一首一篇** | `组-序`(`1-1` = 五言古诗第一首) | 有《诗题》段,`poemTitles: true` |
| **宋词** | **一首一篇** | 纯章号(`3` = 第三首) | 一首即一章,不需细粒度键 |
| **元曲** | **一首一篇** | 纯章号 | 同上 |

⚠️ 唐诗走「组-序」键的机制与诗经同一套(`check-data` 的 `chapterText` 遇此键会把
**引文校验池收窄到单首**)。宋词元曲是普通章键,别混。

**体例(owner 2026-08-05 定,覆盖此前写的 3000–4500)**:**2000–4000 字**,按名气浮动
——**名篇多写、无名的短写**,不必篇篇等长;3–4 图,无 hero(仅各书首篇可 featured)。
块模型与站内白话同构(`lead/h2/p/quote/figure/list/callout/pull/steps/refs`)。

**该讲什么(owner 原话的六件事,顺序可调、不必生硬分节)**:

1. **创作背景** —— 写这首时是什么年头、什么处境
2. **诗人生平** —— 只给与这首相关的那一段,不写完整年谱
3. **这首诗的场景故事** —— 本事、传说、当时的现场感(**传说标「相传」,不当史实**)
4. **影响** —— 后人怎么用它、化用了哪些句、它进了哪些选本与蒙学
5. **主旨展开** —— 这首到底在说什么,讲透
6. **深度解析** —— 炼字、对仗、章法、声律;有话可讲就展开,没有不硬凑

**写法**:
- 先讲**这首在说什么场景**,再讲**它怎么把话说出来的**(炼字、对仗、章法)。
- 配图优先做**意象图 / 章法结构图 / 声律图**;这一层**允许**做与本诗直接相关的
  「创作那一年的处境」时间线(与第 1、2 件事配套),但不做与本诗无关的完整生平年谱。
- 金句卡必出一张,取本诗最著名的一联。
- **引文 `quote.original` 必须是站内原文逐字子串**,`check-data` 会逐条校。

> ⛔ 第 5、6 件事最容易滑进鸡汤。**「主旨展开」是讲这首诗在说什么,不是讲它教我们什么。**
> 红线见 §6 第一条。

## 5. 家级导读「一家之来路」(第四层)

三组各一篇,数据在 `src/data/<corpus>/school.json`,SOP 见
[school-intro-standard.md](./school-intro-standard.md) —— **但三组都属那份 SOP 里的 C 类**:

> **不成「家」,题目必须换。** 唐诗宋词元曲**不是流派**,是**三种体裁**。
> 写成「唐诗派的谱系」就错了。

题目该问的是「**这一体是怎么成的、怎么变的、怎么衰的**」:

- **唐诗** —— 近体格律怎么在初唐定型;盛中晚的分期依据是什么;
  为什么《唐诗三百首》能压过前面所有唐诗选本。
- **宋词** —— 词何以从「诗余」「小道」变成一代文学;婉约豪放的分法是谁提出的、
  多大程度上靠得住;朱孝臧选词的取向与蘅塘退士有何不同。
- **元曲** —— 曲何以在词之后另起一格(语近口语、可加衬字、韵部不同);
  散曲与杂剧的分野;**为什么它的文献远比唐诗宋词零散**(这正是本站只能自行选目的原因,
  在导读里如实交代)。

体裁是**散文**:`callout`/`list`/`steps` 一律不用(`check-data` 已禁),`pull` ≤1,小标题意象化。

## 6. 铁律(三组共通)

1. **不作心灵鸡汤、不作励志格言。** 最重要的一条。
2. **原文一律来自管线,严禁手改、严禁凭记忆补写。** 抓不到就是收不了。
3. **词牌曲牌必须与题目分清。**
4. **本事传说与史实分开标。**
5. **元曲选目是本站编纂行为,须始终显著标明**,不得让人误以为是传世选本。
6. **不作现实影射。**
