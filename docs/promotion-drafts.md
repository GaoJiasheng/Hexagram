这一年下班后陆续做的一个古籍研读站【确认：「这一年下班后」是代拟的说法，按实际情况改】：https://hexa.gavin.pub

说一下怎么做的，这里大家可能更关心这个：

- **纯前端静态站。** React 19 + Vite，没有后端，托管在 Cloudflare Pages。收藏、笔记、阅读进度都存 localStorage，不登录就能读完全部内容。登录只是可选的，用来换设备同步和在章末留言（这部分走 Pages Functions + D1）。
- **原文和人工内容分层。** 原文由脚本从维基文库抓取、繁转简、按章切片，生成物不许手改；发现原文有问题，只能改抓取脚本再重跑。译文、注释、延伸写在另一套源文件里，构建时合并。这样原文和「我们写的」永远分得清。
- **校验闸。** `check-data` 在每次数据变更后跑：注释的词必须是原文的精确子串、译文段数必须和原文对齐、白话文章里的每一句引文必须能在该章原文里找到。跨派对辩那一块，每一轮发言都锚着一句真原文，同样逐句校验。
- **加一个站基本不碰平台代码。** 站点是一份 registry 配置（主题色、导航、分组），阅读器是通用的，加一家主要是加内容。
- 搜索是构建期把索引拆成分片懒加载，全站一个搜索框，能搜原文、译文、注释。
- 译注和白话长文主要用大模型起草，我负责审校和定规矩。跋里写明了。【确认：保留】

几个可以先点开看的页面：

### 3. 豆瓣（读书类小组 / 广播）

**标题**

> 自己做了一个读古书的地方，说说为什么

**正文**

少时读古书，先喜欢的是宋词的婉转、骈文的对仗，贪的是辞藻。年纪大一些，才慢慢读进文字背后的道理。可一直有个麻烦：手边的本子要么只有白文，读到一半卡在一个字上；要么注释太多，原文被淹没了；译文和原文分在两处，来回翻。

所以我给自己做了一个地方，把这些摊在一起。原文一段，译文一段，难字点开才出注释，不点就不打扰。章末有一段延伸，讲这一章在思想史上的位置。再往后是一篇长一点的白话导读，适合读完原文还想多想一会儿的时候。

举两个我自己读得最顺的例子。

读《道德经》，底本用的是王弼注本的分段，所以每章比通行排印本切得细一些，译文和注释一段对一段。读到某章时可以看到同一个概念在《庄子》《列子》里怎么被接着讲，有一个「义理互见」把几处原文并排放着，不替谁下结论。

读《古文观止》，凡是现在语文课本里收的篇目（比如《出师表》《岳阳楼记》），正文照课本的字句和标点；课本和传世底本不一样的地方，在延伸里如实写出来。给孩子陪读的时候很省事。

还有些是我刻意不做的：中医书只当文献读，不讲方子怎么用；命理书只讲书里怎么说，不给人算；佛经道经不劝信；几部近年流行、托名古人的「谋略书」，页面上显著标着疑为现代伪作。

一共收了 81 部，从易经、诸子、佛经到唐诗宋词元曲。不用登录，没有广告。译注多由大模型起草、我逐批审校，难免有错，欢迎指正。

https://hexa.gavin.pub

**建议发帖位置**：读书类、古籍 / 国学 / 古典文学类小组，或个人广播。先确认小组是否允许发外链，很多读书小组禁止推广帖，宁可发在个人广播里。
**配图建议**：道德经一章的阅读页（注释气泡展开）`/dao/daodejing/1`；古文观止目录或一篇课本篇目，如 `/guwen`（首页按卷分组）；名句集 `/mingju`。

### 4. 知乎（文章）

**标题**

> 我做了一个读古书的网站：81 部典籍，原文一字不许手改

**正文**

**缘起**

我小时候读古书，读的是辞藻。后来才读进一点道理，想找个地方安放它们。城市里的日子很满，这个念头放了很多年，直到近来有了大模型能分担大量案头工作，才真的动手。

现在它叫「观象」：https://hexa.gavin.pub 。收了 81 部书，分成十六个研读分站：易经、道藏、儒、佛、阳明心学、法、墨、兵、纵横、中医、谋略、唐诗、宋词、元曲、古文、命理。

**每一章长什么样**

原文一段，白话译文一段，一一对齐。原文里的难字难词有下划线，点开是一条简短注释，不点就不显示。章末是「延伸」，讲这一章和别的书、别的家怎么接上。最后是一篇几千字的白话深读文章，有图，有时间线，把这一章放回它的语境里讲。

除了逐章读，还有几样横着串的东西：一条全站时间轴，把书和人摆在同一根朝代轴上；六十多人的人物志；一千三百多条名句；一个「百家争鸣」，让儒、墨、道、法等围着一个题目对辩，88 场辩论里每一句发言都引自真实的原文，并由脚本逐句核对。

易经那一站多一个推演工作台，金钱卦、大衍筮法、梅花易数、八宫纳甲都按规则表实现，用来理解古人怎么起卦。工作台只解释卦象，不断吉凶。

**原文一个字都不许手改**

这是整个站最硬的一条规矩。原文全部由脚本从维基文库等公版底本抓取，繁转简，按章切好，生成的文件谁也不许直接编辑。发现原文有错，只能去改抓取脚本，再整体重跑。译文、注释、延伸是另一层，存在别的文件里，构建时才合在一起。

这样做的好处是，原文和「我写的」永远分得清。坏处是费事：有一次为了统一一批生僻字，一不小心整站重抓，结果把后来管线的各种改动一并带进了旧书，只好逐书比对差异，把不该变的还回去。从那以后，全局改字改用映射脚本，不再重抓。

**一本夹带了民国评注的电子本**

命理那一组收《子平真诠》时，用的电子本通读过一遍，也做过关键词扫描，判断是清人原文。后来在读库的时候偶然觉得有一段语气不对：列「一、二、三、四、五」那样归纳取用之法，不像乾隆年间的人说话。回头查，才发现那是民国徐乐吾评注里的话，被剥掉了标签混进正文，前后一共十几段。

那时译注已经做完了。只好返工，并定下一条规矩：不是维基文库的电子本，入库前必须找一个独立的白文本逐段对校；找不到第二个本子的，宁可不收。现在校验脚本里也留了一道闸，防止这些段落再混回来。

**有几件事是刻意不做的**

- 中医书当医学史文献读，不讲功效用法，不给诊疗建议，页面上写明「非医疗建议」。
- 命理书只讲书里怎么说、为什么这么说，不替人算命，排盘工具只排结构不出判断。
- 佛经道经讲思想与源流，不劝信。
- 《罗织经》《小人经》这类近年流行、托名古人的书，收进来是当作文献现象看，页面显著标出「托名·疑现代伪作」，延伸里指出它们偷换史实的地方。

**最后**

译注和白话文章主要由大模型起草，我定规矩、做审校。量很大，错一定还有。如果你读到错字、错译、错注，欢迎在章末留言，或者从站里的「跋」找到我。

不用登录就能读全部内容，没有广告。【确认：是否加一句 iOS App】

（约 1150 字）

**建议发帖位置**：知乎专栏文章；可加话题「古籍」「国学」「独立开发」「中国古代文学」。也可以拆出「夹带民国评注」那一段，单独回答「古籍电子本可靠吗」一类问题，文末附链接。
**配图建议**：文章开头一张道德经阅读页 `/dao/daodejing/1`；「百家争鸣」段配 `/debates/map`（论辩图谱）；「推演」段配 `/workbench`；「不做什么」段配一部谋略伪书的目录页，显出「疑现代伪作」徽标，如 `/moulue/luozhijing`(slug 以站内为准）。
**要避免的事**：知乎对「回答里只放链接、硬广」会折叠或限流，回答问题时正文要自成内容；不要在多个问题下复制同一段回答；文中不放二维码、不放联系方式。

搜下来，专门收「国学 / 古籍网站」、又开放自助提交的导航站很少，搜到的多是高校图书馆的资源指南（不开放提交）或建站模板。只列能核实的：

| 站 | 网址 | 怎么提交 | 门槛 |
|---|---|---|---|
| HeyBlog（中文博客列表导航） | https://www.heyblog.net | 站内「提交博客」（`/site/submissions/new`） | 定位是个人博客，本站不完全对口；是否需登录、有无审核标准页面未写明，提交前看其社区规范页 |
| Hacking Chinese Resources | https://challenges.hackingchinese.com/resources | 注册账号，导航栏「Submit」 | 新账号要等约一天才能提交；读者是学中文的外国人，本站全中文，对口程度一般 |

另外两类可以考虑，但不是导航站：高校图书馆的古籍资源指南（如威斯康星大学、多伦多大学东亚图书馆）只能写信给馆员推荐，收不收全看对方；维基文库的「古籍資源」页由社群编辑，收的多是图像库与数据库，不建议自己去加自己的站。
