# 二十一期 · 《赛博:百家争鸣》——跨派义理对辩

> 模块名 **《赛博:百家争鸣》**。开篇词(固定):**「天下同归而殊途,一致而百虑」**(《系辞下》)。
> 本期在已成的 55 部典籍 + `concepts.json`(跨派概念聚类)+ `booksIndex`(全站书名→章)之上,
> 把"诸家在同一题目上各执一词"做成一个**可点、可看、有动画**的对辩模块。**纯离线**:辩论内容
> 预先策展产出为 JSON,页面上点点点即看,不接在线 LLM。**不评输赢**(义理本无胜负)。

---

## §0 定位与铁律

**定位**:这是 review「织成网」主线的收口——前期把书织成网(自动链/搜索/互见/专题),
本期把**人**织成网(诸家就同一题目对辩)。形式取历史原型:稷下学宫的百家争鸣、宋代书院的
**会讲**(朱陆鹅湖之会)、唐宋**三教论衡**——皆"辩而不判胜负"。

**入场诸家**(8 家 + 易经做东道):
- 儒(论语/孟子/荀子/大学/中庸/孝经/颜氏家训/近思录)、道(老/庄/列/文子/参同/黄庭…)、
  佛(心经/金刚/坛经…)、法(韩非/商君/慎子/尹文子)、墨(墨子)、兵(孙/吴/司马/尉缭/三略/六韬)、
  纵横(鬼谷子/战国策)、心学(传习录/大学问)。
- **易经**不下场对辩,做**东道/会通**:开篇题词出《系辞》;个别天人/变常题以系辞之言入席。

**铁律(硬约束,与全站一致)**:
1. **中医不入场**、**谋略不入场**——二者是"落地的操作 / 伪书批判材料",不是一家**思想**流派。
   数据层禁止其作为参辩家(check-data 校验)。
2. **不评输赢**:无比分、无"胜/负/赢/碾压"等字样;编者小结只述"分歧落点与各家旨归",不判高下。
3. **每句有据**:每个发言必挂一段**真原文**(`cite.quote` 须为该章原文的精确子串,与「桥」/锚注同校验),
   并可跳回阅读器。AI 仅"为某立场择取并转写最贴切的原文",不凭空造论。
4. 佛只在**义理层**(无常/无我/空)入辩,不下果报/往生断语;法墨兵纵横如实呈思想,不作现代政治影射、
   不作权术施用教程;道藏不作信仰宣化、不下成仙断语。
5. 全程标注「**AI 演绎·拟构,以原文为据**」,非权威定论。


### §2.2 索引 `index.json`
```jsonc
{
  "epigraph": { "text": "天下同归而殊途,一致而百虑", "source": "系辞下" },
  "topics": [
    { "id":"renxing", "title":"人性之辨", "category":"性与心",
      "question":"人性本善、本恶,还是无善无恶?",
      "schools":["meng","xun","yang"], "turns": 9, "concept":"人性之辨" }
    // turns/schools 由各辩文件派生回填(gen 脚本写入),列表页/每日一辩只读 index
  ]
}
```

### §2.3 单场 `renxing.json`
```jsonc
{
  "id": "renxing",
  "title": "人性之辨",
  "question": "人性本善、本恶,还是无善无恶?",
  "framing": "编者:孟子道性善,荀子言性恶,阳明谓无善无恶心之体——三家非争对错,而辨工夫入手处不同。",
  "schools": [
    { "key":"meng", "label":"孟子", "group":"ru",  "seal":"观仁", "stance":"性善" },
    { "key":"xun",  "label":"荀子", "group":"ru",  "seal":"观仁", "stance":"性恶" },
    { "key":"yang", "label":"阳明", "group":"xin", "seal":"观心", "stance":"无善无恶·良知" }
  ],
  "rounds": [
    { "phase":"立论", "turns": [
      { "school":"meng", "rebut":null, "point":"恻隐之心人皆有之,性本善。",
        "cite":{ "corpus":"ru","slug":"mengzi","ch":11,
                 "quote":"乃若其情,则可以为善矣,乃所谓善也","label":"孟子·告子上" } },
      { "school":"xun",  "rebut":null, "point":"…", "cite":{…} },
      { "school":"yang", "rebut":null, "point":"…", "cite":{…} }
    ]},
    { "phase":"诘难", "turns": [
      { "school":"xun", "rebut":"meng", "point":"…", "cite":{…} },
      { "school":"meng","rebut":"xun",  "point":"…", "cite":{…} }
    ]},
    { "phase":"申辩", "turns": [ … ] }
  ],
  "coda": "三家分歧在『性』字所指:孟言其端、荀言其质、阳明言其体。工夫遂分扩充、化性、致良知。"
}
```

**字段约定**
- `schools[].group/seal`:决定印章头像与该席主色(取该站 `--accent`)。同组多家(孟/荀)各自独立 key。
- `turns[].rebut`:指向被回应的 school key(或 null=立论)。**画论辩图谱的边**。
- `turns[].cite`:`{corpus,slug,ch,quote,label}`;`quote` 须为该章原文精确子串;`label` 展示+经 booksIndex
  `chapterHref` 解析跳转(短经单页走 `#corpus-ch-N` 锚)。
- **轮数上限 100**:`rounds` 内 `turns` 总数 ≤ 100(check-data 校验)。多数题 12–40 轮即收。

### §2.4 与 `concepts.json` 同源
辩题 `concept` 字段对应 `concepts.json` 的聚类 `term`;聚类的 loci 即该辩各家**立论锚章**的种子。
`/concepts` 卡片据此挂「→ 入争鸣」;新增辩题优先复用已 grep 验证的聚类 loci。

## §3 页面与交互

### §3.1 辩题库 `/debates`
- 开篇题词横幅(系辞句 + 出处,弱金石感)。
- 辩题按 §7 的**类**(性与心/工夫/治道/伦理/天人/名实言辩/生死/礼乐文/组内/会通)分栏。
- 卡片:辩题名 + `question` + **参辩印章一排**(seal,各着该家主色)+ 「N 家 · M 轮」+ 分歧一句。
- 卡片 hover/点击有微动效(印章轻浮起);点进 `/debates/:id`。

### §3.2 单场对辩 `/debates/:id` —— 三层
**① 圆桌布阵**(顶部):辩题印居中,参辩印章环绕成席(2 家左右对擂;3+ 家扇形/圆桌)。
轮到谁发言,谁的席**亮主色**、其余黯。下方一行 `question` + framing。

**② 回合流**(主体,"播放感"来源):按 `phase`(立论→诘难→申辩→…)分段,每发言一张卡:
- 印 + 家名 +(若回应)「**驳 · 孟子**」徽
- **论点**(`point`,大字转写)
- **「据」**:`cite.quote` 原文(默认折叠,点开展)+ `读原文 →`(跳阅读器)
- 控制条:`▶ 自动展开`(逐回合淡入推进)/ `下一回合 →`(手动)/ 回合圆点进度 / `跳到收束`
- `revealed`(已展开到第 n 轮)React state 驱动;未展开的卡不渲染或半隐。

**③ 论辩图谱**(侧栏 @桌面 / 折叠 @移动):SVG,**印=节点,朱砂线=`rebut` 关系**,随回合
**逐条画出**(stroke-dashoffset)。点节点→滚到该家最近发言。一图看尽"谁驳了谁"——把「织成网」
真画成网。

**收束**:`coda` 编者小结淡入(只述分歧落点,不判胜负)+ 全图谱一次"全亮"脉动 + 「换一辩」「回辩题库」。

### §3.3 动画规格(本期的"酷炫"在此;纯 CSS keyframes + SVG,无动画库)
- **开坛**(进入 `/debates/:id`,~900ms):① 辩题印 `scale .9→1 + fade`(180ms);② 参辩印章自四边
  **落座**(staggered `translate + fade`,各延迟 80ms,落定带轻 overshoot);③ 题词/framing 自下淡入。
- **回合推进**(每揭一轮):发言卡 `translateY 14px→0 + opacity 0→1`(260ms ease-out);发言席印
  `pulse`(主色光晕一次);若 `rebut`,朱线自被驳印 → 发言印 `stroke-dashoffset` 由满到 0(700ms)。
- **自动展开**:每轮间隔 ~2.2s(可调速 0.5×/1×/2×),到收束停;任意时刻可切手动。
- **收束脉动**:图谱所有边一次 `opacity/stroke-width` 脉冲(600ms)。
- **降级**:`@media (prefers-reduced-motion: reduce)` 一律改为瞬时显示(无位移/无 draw-on);
  自动展开仍可用但无补间。
- **性能**:回合流长(至多 100 轮)→ 发言卡 `content-visibility:auto`;图谱节点数 = 家数(≤~6),边数小,
  SVG 轻量。

### §3.4 每日一辩(首页弹窗)
- **组件** `DailyDebate.jsx`:首页/门户首次访问当日**自动弹**一个卡片式浮层(非阻断硬 modal,
  纸色卡 + 遮罩,点遮罩/Esc 关)。内容:「每日一辩 · {日期}」+ 辩题 + `question` + 参辩印章 +
  `进去看 →` / `今日不再提示`。
- **选题**:日期+「daily」hash → `index.topics` 取模(同 `今日一卦/今日一章` 既有套路,每天变、确定性)。
- **不重复弹**:`localStorage guanxiang.v1.dailyDebateSeen = 'YYYY-MM-DD'`;当日已关则不再弹(不入
  DATA_KEYS 导出)。手动入口长存(门户链接 / `/debates`)。
- **挂载处**:易经首页 `/`(默认着陆)+ 总门户 `/hexagram`。其余分站首页不弹(免跨组叨扰),
  但 nav/门户可达。

### §3.5 阅读器 / 概念页接入
- `SeeAlsoBlock`(章末)若当前 `corpus:slug:ch` 命中某辩的某 `cite`,加一行「本章入『X 辩』· {该家}{立论/诘难} → 看争鸣」。
- `/concepts` 概念卡:`concept===title` 的辩题挂「→ 入争鸣」。

## §5 内容生产工序(离线,审过才发,沿用译注那套纪律)
每辩一个并发 workflow(仿 `gen-zhuzi-wf` + `assemble-newtexts`):
1. **每家一个 agent**:据该家**真实章节**起立论/诘难,每发言**必引一段真原文**(给定可引章节范围),
   schema 强约束输出 `{school,point,rebut,cite}`。
2. **校 agent**:逐条核 `cite.quote` 是该章原文精确子串、`rebut` 指向真 key、守 §0 铁律、无"胜负"字样;
   不合即弃该条或回改。
3. **编者 agent**:写 `question`/`framing`/`coda`(中立,不判胜负)。
4. 程序化装配 → `src/data/debates/<id>.json` + 回填 `index.json`(turns/schools)。
5. `check-data` 过才提交;一题或一类一批、一批一发版。

**底本**:引文一律取各书既有生成物(`*/classics/*.json`)原文,不另抓、不手改。

## §6 check-data 校验(新增 `checkDebates`)
对 `src/data/debates/*.json`:
- 每 `school.group` ∈ 入场 8 家(**禁 zhongyi/moulue**),`seal` 非空;
- 每 `turn.cite.quote` 是 `{corpus,slug,ch}` 对应章原文的**精确子串**(载 classics 比对,同锚注校验);
- 每 `turn.rebut` 为 null 或本辩内真 school key;
- `rounds` 内 turns 合计 **≤ 100**;
- 全文无禁词(赢/胜负/输/碾压…);
- `index.json` 与各辩文件 id 一一对应,`turns`/`schools` 回填一致;
- 覆盖仪表:辩题数 / 总轮数 / 参辩家次。
