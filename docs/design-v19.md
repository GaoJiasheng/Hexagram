## 0. 铁律(最高约束,贯穿译·注·延 —— 类比佛「不宣化」、易「禁算命」)

医典上线必须守住:**研习不诊疗。** 本站取**医学史、文献、学术研习**视角,非诊疗工具:

1. **译文**:平实直译经文字面义,不附「现代医学解读」、不教读者据此自我诊断或施治。
2. **注疏**:释字词、名物、术语、源流;**方剂只释方名/药名/出处,不述主治、功效、用法、用量、宜忌**(避免误导自疗)。脉象、证候等概念作文献训诂,不导向「对照自查」。
3. **延伸**:讲医学史、人物(扁鹊、仓公、华佗、张仲景、皇甫谧、孙思邈、李时珍…)、学派源流(伤寒/温病、医经/经方)、概念的思想史(阴阳五行入医、藏象、运气);**不作养生指导、不下病症吉凶或疗效断语、不荐方荐药**。
4. 全站显著声明:**内容为古籍研习,非医疗建议;如有不适请就医。**(题解/首页副标注)

> 这条铁律比佛/易更要紧(涉健康安全与责任),开工时校验代理须专项扫禁忌词(主治/功效/服法/治愈/包治/对症…在「方剂—自疗」语境下)。

## 3. 工序(对标道藏 + 中医特殊处)

通用七步同道藏/儒佛:config 切片 → 原文录入(严禁手改)→ 全译 → 锚定注疏 → 篇章延伸 → authorNote → check-data。中医特殊:

- **术语密集**:藏象、经络、气血津液、五运六气、脉证、方药——锚定注疏量大,长词专名优先;**术语表(对标易经 glossary)价值高**,可同期建「中医名词」表(阴阳/五行/藏象/卫气营血/六经…)。
- **内经问答体**(黄帝问、岐伯对)近论语语录:逐章逐段译,人名(黄帝/岐伯/雷公/少师)保留。
- **方剂/药条**:经文照译;注疏延伸守铁律(见 §0)。
- **分章**:素问/灵枢各篇为章(splitHeadings 或子页);伤寒论按条(可逐条为段、按篇/法归章);本草经按上中下三品 + 逐药为段。

## 4. 体量与批次(并发)

| 书 | 估算(选篇后) | 批次 |
|---|---|---|
| 素问选篇 | ~3 万字 / 15–20 篇 | 基建批 → 并发(每数篇一单元,约 4–6 批) |
| 灵枢选篇 | ~2 万字 / 10 篇 | 并发约 3 批 |
| 伤寒论 | ~5 万字 / 398 条 | 并发(按篇/法切片,约 6–8 批) |
| 本草经 | ~2 万字 / 365 味 | 并发(上中下三品 + 逐药,约 4 批) |

> 总约 12 万字。流程:**先铺脚手架 + 四书原文录入(选篇配置)一批**,再并发填译注延(校验代理专项守铁律),逐书 done、收尾发版。
