## 1. 选题铁律(owner 明确要求,违反即返工)

> **「你要确保真的是各家学派都有相同 topic 下的不同看法。要真实的这种,而不是为了一个 topic 往上硬凑。」**

判据两条,缺一不可:
1. **每一方都得对同一个问题有明文表态**——不是话题相邻。如「诗教」曾被否掉:墨子只反「乐」不反「诗」(引诗还是正面引用),三方并不在同一问题上对立。
2. **不与现有辩题重叠**。如「无善无恶」曾被否掉:与既有《人性之辨》(孟/荀/阳明)、《心之本体》(程朱/阳明/庄子)是同一批人同一个轴。

**宁可少做,不可硬凑。** 纵横目前仅 2 辩且无未引用典籍,已确认**不为凑数硬开题**。

## 2. 怎么找选题:概念索引法(不要凭记忆)

凭回忆只能捞到个位数;跑一遍索引能到 20+。方法:

1. **载入 9 组全部原文**(含 yijing,98.6 万字):
   ```python
   corpus={}
   for g in ['ru','dao','fo','xin','fa','mo','bing','zong','yijing']:
       txts=[]
       for f in glob.glob(f'src/data/{g}/classics/*.json'):
           for ch in json.load(open(f))['chapters']:
               txts.append(''.join(p['original'] for p in ch['paragraphs']))
       corpus[g]='\n'.join(txts)
   ```
2. **用哲学概念表逐个测出现率**(每万字 ≥2 次且 ≥5 次绝对值 才算"真被讨论"),得出「该概念被几个学派讨论」。
3. **与现有辩题比对**,挑高跨派 × 未开辩者。
4. **逐个 grep 验对立相**——这一步不能省(上一轮就是没验,提的 5 个里 2 个当场作废)。

**⚠️ n-gram 自动提词行不通**:古汉语高频二字全是「而后/之道/所谓/君子」这类虚词搭配,提不出概念。必须概念表 + 实测。

## 5. 做一辩的工序

### 数据结构
```jsonc
// src/data/debates/<id>.json
{ "id","title","category","concept","question","framing",  // framing 末句惯例:「此为会讲,不判胜负。」
  "schools":[{"key":"短key","label":"孟子","group":"ru","seal":"观仁","stance":"性善"}],
  "rounds":[{"phase":"自取名","turns":[{"school":"key","rebut":"另一key或null","point":"25–55字",
             "cite":{"corpus":"ru","slug":"mengzi","ch":11,"quote":"原文精确子串","label":"孟子·告子上"}}]}],
  "coda":"…" }
```
同时在 `index.json` 的 `topics` **末尾追加**登记项(比辩题文件多 `division`/`turns`/`status`,
`schools` **不含 key**;组内多方/跨组会通另加 `"format":"intra"|"synthesis"`)。

`seal` 按 group 填:ru=观仁 dao=观道 fo=观空 xin=观心 fa=观法 mo=观兼 bing=观兵 zong=观衡 **yijing=观象**。

### 铁律(check-data 会拦)
1. **`cite.quote` 必须是站内原文精确子串**(`text.includes(quote)` 逐字校验)。
   **先 grep 再落笔,不许凭记忆默写**——站内底本是**繁转简**、标点多为全角,记忆里的版本几乎必然不同。
   取原文的方法(与 check-data 完全一致):
   ```bash
   python3 -c "
   import json;d=json.load(open('src/data/ru/classics/lunyu.json'))
   c=[x for x in d['chapters'] if x['no']==2][0]
   print(''.join(p['original'] for p in c['paragraphs']))"
   ```
2. **不评胜负**:point 不得含 胜负/输赢/赢了/碾压/击败/完胜/败北/谁赢/分高下/谁对谁错。
3. **中医(zhongyi)、谋略(moulue)不入场**,引文亦不得出自这两组。
4. `rebut` 只能指向本辩已有 key。**每位参辩方至少被 rebut 一次**(不许有人全程没被接茬)。
5. `point` 25–55 字。
6. 各组红线照旧:佛研习不宣化不劝信、道不宣化不下成仙断语、兵思想史视角不作实操教程、托名伪托如实标注。

### 结构自由(2026-07 起)
**不要再用「立论→诘难→申辩」三段式**——现有 **163 种** phase 名(夹击/互诘/追问/诘幻/推刃/按剑/鼎足相攻/仰观/畛外/极数/投钩/栩栩/散木…),
按内容取名、**新辩之间及与既有 phase 名尽量不重复**,轮数 4–12 按需要定,不必等长。

### 收尾
`npm run check-data`(无 ✗)→ `npm run build` → `npm test` → 提交。
**并发多辩时**:index.json 会被同时追加,务必**重读最新内容 → 程序化 splice → 写后复查两边条目都在、无重复 id**。
