## 三、需要你知道的三件事(都已处理,但值得你过目)

1. **《子平真诠》底本夹有民国徐乐吾的文字。** 殆知阁电子本出自 1936 年评注本一系,标签被剥掉了,「通读 + 版权词表」两招都没查出来。
   后以三种独立白文本逐段对校,剔除书末整篇「附论杂格取运」+ 另 12 段(含著名的「五种取用法」)。49 篇 → 48 篇。
   有一段评注本标作原文而白文本皆无,**存疑未收**(可能少收了沈孝瞻一段话)。同法复核《穷通宝鉴》:干净。
2. **三部四库本是白文,一个标点都没有**(三命通会 / 李虚中命书 / 玉照定真经,约 46 万字)。做了「断句层」:标点当编辑内容另存,
   管线逐段核「去标点后与底本逐字相等」才采用。**目前尚未断句**——要等这三部的译注 workflow 跑(约 2500 万 token 量级),见下。
3. **译文错位。** 两次抓到整段错位(穷通命例横表带偏代理;大章切片下标歧义)。成因都已根治(结构化 / 提示语加首末段锚),
   并加了用字留存率的错位扫描进 check-data。现四部书 0 错位。
