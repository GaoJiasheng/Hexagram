## 四、App 隐私(营养标签)

> ⚠️ **2026-08-03 重写**:原填「Data Not Collected」已不成立。**填错等于向 Apple 作不实申报。**
> 下表按 build 48+ 的 iOS 端**实际行为**列(已对着 D1 表结构与 `telemetry.js` 逐条核过)。

**需要申报为「收集」的三类**(全部 **Linked to You** = 是,**Used for Tracking** = 否):

| Apple 分类 | 具体项 | 我们实际存什么 | 用途 |
|---|---|---|---|
| Contact Info | **Email Address** | 注册/登录的邮箱(`users.email`) | App Functionality(账号标识与找回) |
| Identifiers | **User ID** | 账号 id 与头像编号(`users.id` / `avatar_seed`) | App Functionality |
| User Content | **Other User Content** | 云同步的研习数据:收藏、批注、阅读与研习进度、推演历史、偏好设置(`user_data`) | App Functionality(换设备接着读) |

**不申报(iOS 端确实没有)**:
- **Usage Data / 阅读埋点** —— `telemetry.js` 的 `supportsTelemetryOrigin()` 在 `VITE_CAP === '1'` 时直接
  返回 false,**打包进 App 的构建不发送任何阅读事件**。网页版才有,且与账号不关联。
- Diagnostics / 位置 / 通讯录 / 相册 / 浏览记录 / 购买 / 财务 / 健康 —— 一律没有。
- 广告标识符、跨站追踪、第三方分析 SDK —— 没有。Turnstile 只在**网页端发评论**时加载,
  App 内评论只读、不渲染发帖框,故不加载。

**其他必填**:
- 隐私政策 URL:`https://hexa.gavin.pub/privacy`
- **账号删除**:App 内已提供(设置 → 账号 → 注销账号,需抄一遍邮箱确认),
  满足 **Guideline 5.1.1(v)**「支持注册的 App 必须能删账号」。

## 六、截图规格 + 模拟器捕获配方

首发通用 App 至少要两套(每套 3–10 张,建议 5 张):
- **iPhone 6.9″**:必需。用 **iPhone 17 Pro Max** 模拟器出图(6.9″ 类,ASC 接受)。
- **iPad 13″**:必需(因通用 App)。用 **iPad Pro 13-inch** 模拟器出图。

建议 5 屏(明暗随意,内容自选):①易经首页/总门户 ②卦详情(卦画+爻辞+悬停注释,挑个漂亮卦如乾/未济) ③白话深读整页(hero 封面+配图,挑加粗密的章) ④推演工作台(起卦+断法) ⑤学堂/义理专题。

**捕获配方**(在本仓库根目录):
```bash
# 1) 构建原生档 web + 同步进 iOS 壳
npm run build:cap && npx cap sync ios

# 2) 启动目标模拟器(二选一,逐台来)
xcrun simctl boot "iPhone 17 Pro Max"     # 6.9″
#   或
xcrun simctl boot "iPad Pro 13-inch (M5)" # iPad 13″
open -a Simulator

# 3) 在 Xcode 里 Run 到该模拟器(scheme=App),或:
npx cap run ios      # 选中对应模拟器

# 4) App 里手动点到想要的那一屏,然后逐张存图(准确像素、直接可上传):
xcrun simctl io booted screenshot ~/Desktop/hexa-1.png
#   … 点到下一屏,重复,改文件名 hexa-2.png / hexa-3.png …
```
`simctl io booted screenshot` 直接出模拟器分辨率的 PNG(iPhone 17 Pro Max = 1320×2868,iPad 13″ = 2064×2752),**尺寸即 App Store 所需,无需再改**。若要加中文标题边框做营销图,用任意工具套模板但保持画布尺寸不变。

> 想让我替你挑屏逐张拍,可单独开一轮:我会装 App、逐屏截图给你选,你定明/暗与卦目即可。
