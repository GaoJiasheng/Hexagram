# 中国大陆区上架专项:ICP 备案与内容审查

> 你选了「含中国大陆」。这一部分几乎全是**你本人的账号 / 主体 / 备案操作**,代码侧帮不上忙,但门槛很硬,先看清楚再决定是否值得为陆区付出。
> 结论先行:**大陆区上架的真正拦路虎是 ICP 备案 + 占卜/宗教内容审查,个人开发者通常两条都难过。强烈建议先发「除中国大陆外的全球区」上线,陆区作为后续单独攻坚。**

## 一、ICP 备案(硬门槛,自 2023 年起强制)

工信部要求:在**中国大陆区 App Store** 上架的 App,必须完成 **ICP 备案**(应用备案 / 域名备案)。App Store Connect 在你选中国大陆区时会要求填 **ICP 备案号**,没有就无法提交陆区。

拿到备案的前提(个人几乎都卡在这):
1. **中国境内主体**——个人可用大陆身份证做「个人主体」备案,但很多云厂商对 App 备案要求企业主体;个人主体能备的类目受限。
2. **境内云服务器 + 该厂商代备案**——备案要挂靠一个有资质的境内接入商(阿里云 / 腾讯云等),且**服务器必须在境内**。你现在纯前端托管在 Cloudflare(境外),不满足;若走陆区需在境内云厂商买一台服务器并把域名解析/备案挂过去。
3. **域名已备案**——`gavin.pub` 是 `.pub` 顶级域,需确认该域可在国内备案(部分新顶级域国内不予备案,可能要换 `.com`/`.cn`)。
4. 备案周期通常 **1–3 周**,期间要邮寄/上传证件、拍幕布照等。

> ⚠️ 你当前部署是 CF Pages(境外),App 本身是 Capacitor 本地打包不依赖你的服务器——但**ICP 备案是对「App」这个东西的行政要求,与 App 技术上连不连你的服务器无关**,不能因为 App 离线就免备案。

## 二、内容审查(即便过了备案,陆区还有这层)

陆区 App Store 对以下类目额外敏感,你的内容全中:
- **占卜/命理**:易经推演即便你定位「义理研读、非算命」,陆区对「周易占卜」类历史上收紧过,需强调**文化教育**属性,去掉任何「预测吉凶/改运」的措辞与截图。
- **宗教**:佛/道内容——陆区宗教类 App 受《互联网宗教信息服务管理办法》约束,需相应许可;纯经典**文本研读+文献注释**通常按「传统文化/古籍」处理风险较低,但审核尺度不定。
- **中医**:方剂内容——坚持「研习不诊疗、非医疗建议」声明(你已全站铺好),别出现诊疗/用量指导。

对策:陆区提交时把类目、文案、截图全部收敛到「**国学古籍 / 传统文化教育**」,彻底剥离占卜、宗教修行、诊疗任何暗示。你的 App 数据规则本来就守这些铁律,是优势。

## 三、两条路线对比

| | A. 先发 除大陆外全球(推荐) | B. 直接上含大陆 |
|---|---|---|
| ICP 备案 | 不需要 | **必需**(境内主体+境内服务器+域名备案,1–3 周) |
| 内容审查 | 走标准 App Review | 标准 Review + 陆区额外敏感审查 |
| 触达 | 港澳台 + 海外华人(可搜可下) | + 大陆用户 |
| 首发速度 | 快(材料齐即可提交) | 慢(卡在备案) |
| 个人开发者可行性 | 高 | 低—中(备案主体/服务器是真门槛) |

## 四、若坚持陆区,你需要本人去办的清单

- [ ] 确认 `gavin.pub` 能否国内备案;不行则准备一个可备案域名(`.com`/`.cn`)。
- [ ] 在境内云厂商(阿里云/腾讯云)开通账号 + 买一台境内服务器(备案接入用)。
- [ ] 提交 **ICP 备案**(个人或企业主体),等 1–3 周拿备案号。
- [ ] 视需要办理宗教信息服务相关合规(若审核要求)。
- [ ] App Store Connect 陆区填写 ICP 备案号。
- [ ] 陆区文案/截图收敛为「传统文化教育」,剥离占卜/宗教/诊疗暗示。

先把**除中国大陆外的全球区** 1.0.0 提交上线(材料见 docs/appstore-listing.md,你本人就能走完),让 App 先跑起来、拿到用户反馈;大陆区作为 1.x 的独立专项,等你决定投入备案成本时再启动。要我把 listing 文档里的地区自检项按「先发 ex-China」再标一版也行。
