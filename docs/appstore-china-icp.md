## 一、备案:你已有的 vs 还差的

**离线不联网 ≠ 免备案**:App 纯本地打包、无需服务器运行——但大陆区 App Store 的 APP备案是**监管/行政要求**,针对「上架到大陆商店」这个行为本身,与 App 技术上联不联网无关。功能上你不需要服务器,上陆区商店仍要有**备案号**填进 App Store Connect。

| | 状态 | 说明 |
|---|---|---|
| **域名 / 网站 ICP 备案** | ✅ 已有(gavingao.cn) | 说明你已有**备案主体 + 境内接入商**(阿里云/腾讯云之类)。最难最慢的部分已完成。 |
| **APP备案(移动应用程序备案)** | ❌ 待办(轻量) | 2023 起大陆区新增、针对「App 本身」的独立备案。你主体+接入商现成,只需在云厂商备案控制台「新增移动应用」,把此 App 挂到已有主体下。 |

**APP备案怎么做**(在你 gavingao.cn 的备案接入商控制台):
1. 登录你办 gavingao.cn 备案的那家云厂商(阿里云/腾讯云)控制台 → 找「**移动应用备案 / APP备案**」。
2. 在**已有备案主体**下「新增应用」,填 App 名称(观象)、Bundle ID(`pub.gavin.hexa`)、平台(iOS)、分发市场(App Store)等。
3. 云厂商初审 → 报送管局 → 下发**APP备案号**(有了现成主体,通常比域名备案快)。
4. 把备案号填进 App Store Connect 的中国大陆区。
> 具体入口/字段以你那家云厂商为准;不确定就问其备案客服「已有域名备案主体,如何新增一个 iOS App 的移动应用备案」。

## 二、内容审查(与备案无关的另一层,陆区仍在)

陆区 App Store 对以下类目比海外严,你的内容都沾:
- **占卜/命理**:易经推演即便定位「义理研读、非算命」,陆区对「周易占卜」历史上收紧过。文案/截图去掉任何「预测吉凶/改运」字样,强调**文化教育**。
- **宗教**:佛/道内容受《互联网宗教信息服务管理办法》影响;纯经典**文本研读+文献注释**通常按「传统文化/古籍」处理、风险较低,但尺度不定。
- **中医**:方剂内容——坚持「研习不诊疗、非医疗建议」声明(你已全站铺好),别出现诊疗/用量指导。

**对策**:陆区提交时类目=教育、文案/截图收敛到「**国学古籍·传统文化教育**」,彻底剥离占卜/宗教修行/诊疗暗示。你全站铁律本来就守着,是天然优势。

## 三、隐私 / 支持 URL 建议用 gavingao.cn

App Store 的隐私政策 URL 不强制与备案域名一致(放 hexa.gavin.pub 也能过),但既然 gavingao.cn 是你**备案好的域**,用它做隐私/支持 URL 对陆区审核观感更干净、更「合规自洽」。
