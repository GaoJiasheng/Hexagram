## 1. 短经单页阅读器(批次 1)

- 适用:清静经(1章6段)、太上感应篇(1章14段)、阴符经(3章3段)。判定:texts.json 加 `singlePage: true` 标记(仅这三部),DaoTextPage 据此分流。
- 路由不变(`/dao/:slug`):短经直接渲染**单页阅读器**(题解 header + 全文铺开 + 章末延伸 + 左侧章节锚点目录 + 字号/译文工具条);长经保留现状(题解 + 章节格子 → 逐章 DaoReadPage)。
- 单页阅读器布局照 read-page 两栏:左 `read-toc`(章节锚点,点击 scroll 到该章;单章经则列段落小节或仅一项),右 `read-content`(各章 `<h2>` + 段落 ClassicText 挂 anchors + 章末 YanyiBlock)。
- 复用 read-toolbar(字号 + 译文开关)、ClassicText、getDaoAnchors;hash 锚点定位(章切换走锚点不走路由)。

## 2. 每章延伸(批次 1–7)

- 数据 `src/data/dao/yanyi.json`:`{ slug: { "1": ["段落…"], "2": [...] } }`,章号字符串、值为段落数组。
- 组件 `YanyiBlock({ paragraphs })`:章末「延伸」小标题 + 段落;无数据则不渲染。挂两处——单页阅读器各章末、DaoReadPage 章末(长经)。
- 内容分书风格:
  - **道德经**——每章拈出一二核心意旨,接其在思想史/成语/后世引用中的回响(如「上善若水」「千里之行始于足下」之源)。
  - **庄子内篇**——每篇说透寓言(鲲鹏/庖丁/浑沌…)与其哲思,及对文学禅宗的影响。
  - **参同契**——每章点丹道隐语所指、与易象的扣合、注家(彭晓/朱熹/陈致虚)的解读分歧。
  - **清静经/感应篇/阴符经**——清静经接坐忘/重玄学;感应篇接劝善书/功过格传统;阴符经接兵家·道家·丹家三派分解史。
- 篇幅:每章 1–3 段,平实;考证标出处,传说明示,把握不足者宁短毋编。
