# 全站人物志 · 小传派工共用规格(2026-09-25)

站「观象」(古籍研读站,/Users/gavin/work/hexagram)要建全站人物志:一人两段小传。你负责 `renwu-need.json` 里指定下标区间的人。

## 每人两段(paragraphs[0]、paragraphs[1]),各 120–220 字,纯文本、不用 markdown
1. **生平**:字号、籍贯、时代、身份、主要事迹、卒年或活动年代的依据(如「《汉书》本传」「韩愈为撰墓志」),生卒不详的直说不详。
2. **与本站所收之书的关系**:他撰 / 译 / 注 / 编 / 整理了站内哪几部(见 `books` 字段,slug 对应 `src/data/<group>/texts.json`),这些书的底本、真伪、依托、后人增补等情形——**口径必须与站内已有文字一致**:先读该书在 `src/data/<group>/texts.json` 里的 `authorNote`/`caveat`,有书级导读的再看 `src/data/<group>/daodu/<slug>.json` 的开头,有家级导读的看 `src/data/<group>/school.json` 提到他的段落。与这些不合的,以站内为准。

## 铁律
- **四级分级**:共识直写;有考证的标出处(某史某传、四库提要);存疑的明示「一说」「相传」「无考」;**拿不准的宁可不写**——生卒年、籍贯、官职、「首创」「最早」尤其如此,不要为凑字数编。
- **不引 20 世纪以后注家评注文字**(徐乐吾、韦千里、袁树珊等),也不转述其观点。
- 命理人物(group=mingli)只讲其人其书,**不评其术验否、不为其背书**;佛道人物不作宣化;不作鸡汤式颂扬。
- 托名对象(如「旧题鬼谷子」)不是本条主角时不必展开。

## 交付
写到分片文件(路径见派工),形如 `{"<id>": ["第一段", "第二段"], …}`,**只含你负责的人、只写这一个文件、不改仓库任何文件、不 git**。写完自查:每人恰两段、每段 120–220 字(用 `[...s].length` 数)、无 markdown、无 20 世纪注家名。最后用几行回报:写了几人、**没把握因而没写或写含糊的史实清单**(这一条主会话要据此人读复核)。
