## 0 · 五条不变的规矩(观数那轮定下的,原样沿用)

1. **书本来的形状,就是它的导航。** 不给每本书硬套一个花活;先问「这本书原本是什么形状」——矩阵、次第、成对、
   环、谱系——形状是什么,交互件就是什么。形状不明显的书(墨子、谋略五部、清言三书)**不做**,硬做是花架子。
2. **管线只写参数,不画图。** 交互件是 `widget` 块(`{type:'widget', kind, props}`),`schema.js` 一份校验
   浏览器与 check-data 共用;白话 / 导读 / 学堂 / 观书共用同一渲染器,加一种件四处生效。死 SVG 画错了没人查得出,参数错了机器查得出。
3. **每一个点、每一条线,都挂原文出处,check-data 回查。** 五行藏象图的「木→肝→酸→目」每一格是《素问》哪一句、
   月相盘的「三日震庚」是《参同契》哪一章,都用 `kw` 回查原文子串——不凭记忆指章,和观数概念索引一个闸。
4. **铁律不因为「变成了图」就松。** 中医呈现的是**文本的结构**不是诊疗路径;佛不宣化;道不演工法;易不算命。
   件里只排结构、不出判断;各家不一处给开关不拍板。
5. **验收只有一条:「读者动什么 → 悟什么」在页面上真的成立。** 讲推导过程不只给结论;明暗两套;320px 不横向溢出;键盘可操作。
