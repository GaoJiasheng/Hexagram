## 1. 常驻步骤条(批次 1)

- 工作台左栏顶部(起卦标题下、引导框上)常驻三步:**① 起卦 → ② 标动爻 → ③ 读断法**。
- 按状态点亮当前步(纯派生,不存状态):
  - 无 hex:① 进行中(高亮),②③ 灰。
  - 有 hex:① 打勾(✓),② 进行中(动爻可选),③ 可读(右侧已出结果)。
- 视觉:小三段,当前步朱砂、已完成赭石勾、未达灰;移动端横排不换行。
- 不可点(纯指示),避免与方法标签争交互。

## 2. 示范一卦走查(批次 1)

- 引导框内 / 空态加「示范一卦 →」按钮。点击:
  1. 载入示范卦:**乾 · 九五动**(乾之大有,一爻变,爻辞「飞龙在天」最易记),`setHex`+`setMovingLines([5])`+origin 标记 demo。
  2. 启动轻量走查:依次高亮三处并弹一句说明 —— 起卦区(「这是本卦:乾,九五是动爻」)→ 卦变图(「动爻使乾变大有,右为变卦」)→ 断法卡(「一爻变以变爻辞占,故取乾九五『飞龙在天』,下附小象与字词注疏」)。每步「下一步」,末步「完成」,任意步可「跳过」。
- 实现:自写 `GuideTour` 组件(无第三方库),按 CSS 选择器定位目标元素,半透明遮罩 + 目标描边 + 气泡;`localStorage` 记 `guanxiang.v1.tourSeen.workbench` 不强制重弹(仅按钮触发,首访不自动弹,避免打扰)。
- 走查目标用稳定 className(`.workbench-gua` / `.bianhua-row` / `.rule-card`),找不到目标的步骤自动跳过(防御)。

## 3. 学堂「推演入门」专篇(批次 2)

- 新页 `/basics/tuiyan`,LEARN_TOPICS 注册(id `tuiyan`,排在揲蓍/梅花/金钱之前作为总纲;quiz: false)。
- 内容分节(脱锚叙述照 v9 §4:概念为共识级直写,变占规则引《易学启蒙》):
  1. **什么是起卦与推演**——求一卦(本卦)、可有动爻、动则成变卦,推演=把这套关系摊开看。
  2. **四个词**——本卦/动爻/变卦/贞悔(本卦为贞、变卦为悔,与内外卦贞悔两义并存,标明)。
  3. **起卦六法概览**——分两类(输入已知 / 现场起卦),逐法一段+适用场合,链既有 `/basics/meihua`·`/basics/jinqian`·`/basics/shicao`。
  4. **起卦之后:解卦流程**——变占规则简表(无动爻→卦辞、一爻变→变爻辞、…、六爻皆变→变卦辞/用九用六),引《易学启蒙》;再说本站断卦卡的三层(经文+译文 / 彖小象传文 / 字词注疏)。
  5. **动手**——「去推演工作台 →」+「先看春秋筮例怎么用 →」。
- 工作台引导框补一行「第一次用?先读**推演入门** →」链 `/basics/tuiyan`。
