# 书包格式(deskbook)· 标准 v1

> 「观象 · 书桌」读的每一本书,都是一个**书包**:一个 `.deskbook` 文件。
> 本标准公开:任何人都可以照它做一本书,导进自己的书桌。**导入的书只存在自己的设备上,不上传、不收集。**
> 实现与约定以本文件为准;机器可读的结构定义在 `public/desk/standard/schema/`,校验器 `deskbook.mjs`(单文件、无依赖)。

## 0 · 三种体裁,一个格式

| `kind` | 是什么 | 一章里有什么 | 阅读方式 |
|---|---|---|---|
| `classic` 典籍 | 以原文为主的书 | 原文分段(`segs`:原文、译文、注),可带一篇深读文章(`article`) | 原文翻页;章末进深读 |
| `book` 现代书 | 一本书的讲解、消化,或自己写的书 | 一篇文章(`article`) | 纵向长文 |
| `collection` 文集 | 若干独立文章:科普合集、一期刊物、专题 | 一篇文章(`article`),各有作者、日期、出处 | 目录是文章列表,纵向长文 |

三种共用同一套**块**(§3)与**媒体**规则(§4)。典籍沿用书桌现有的全部能力(详注、划线、卦画)。

## 1 · 书包的样子

`.deskbook` 是一个 zip(存储或 deflate,不加密,不嵌套 zip),解开后:

```
book.json            书目清单(必有)
chapters/001.json    每章一个文件,文件名 = 章号补零到三位
chapters/002.json
media/…              图片、视频、封面(可无)
```

- 路径一律用 `/`,只许小写字母、数字、`-`、`_`、`.`;不许 `..`、绝对路径、隐藏文件。
- 只认上面三类内容。**不收任何可执行内容**:HTML、JS、CSS、SVG、字体、脚本一概不收;文字里的尖括号按字面显示。
- `media/` 下可以再分子目录(如 `media/ch01/a.png`)。
- 上限:整包 ≤ 300 MB;`book.json` ≤ 2 MB;章文件 ≤ 2 MB;图片 ≤ 4 MB;视频 ≤ 24 MB;章数 ≤ 2000;zip 条目 ≤ 10000;zip 中央目录 ≤ 16 MB;路径 ≤ 255 字符。

## 2 · book.json

```jsonc
{
  "format": "deskbook",
  "version": 1,
  "id": "u-neijing-daodu-3f9a2c1b",     // 稳定标识,见下
  "revision": 3,                         // 整数,每次重出 +1;书桌据此判断是不是新版
  "kind": "book",                        // classic | book | collection
  "title": "运动解剖学入门",
  "subtitle": "二十个动作讲清发力",       // 可无
  "authors": ["某某"],                    // 这本书包的作者(写讲解的人);可空数组
  "lang": "zh-Hans",
  "summary": "一句话说这本书讲什么(≤ 60 字)",
  "description": "一段介绍(≤ 400 字,可无)",
  "category": "健身",                     // 一个词,书架按它分栏;可无
  "tags": ["解剖", "力量训练"],            // ≤ 8 个
  "source": {                             // 内容从哪来(必有)
    "type": "digest",                     // original 原创 | digest 对别人的书的消化讲解 | public-domain 公版原文 | licensed 已获授权
    "of": { "title": "原书名", "author": "原作者", "publisher": "出版社", "year": 2019 },   // digest / licensed 必有
    "note": "可无"
  },
  "disclaimer": "medical",                // 可无;medical | divination | 自写一句(≤ 120 字),或其中几项的数组。见 §6
  "unit": "章",                           // 章的叫法:章 / 篇 / 卦 / 讲 / 期…
  "theme": { "accent": "#2E7D86", "accent2": "#C7673F", "paper": "#F7F5EE" },   // 可无;三项都可单独缺,缺的用默认
  "cover": "media/cover.jpg",             // 建议竖版 2:3,可无
  "banner": "media/banner.jpg",           // 建议横版 3:2,可无
  "parts": [ { "title": "上篇", "from": 1, "to": 8 } ],   // 可无;有则须连续覆盖全部章
  "chapters": [
    { "no": 1, "file": "chapters/001.json", "title": "肩胛骨先动", "subtitle": "可无", "minutes": 9,
      "summary": "一句话说这一章(≤ 80 字,一行,可无;列表里显示)",
      "author": "可无(文集用)", "date": "2026-10-03", "head": "media/head-001.jpg" }
  ],
  "generator": "deskbook-skill 1.0"       // 可无
}
```

- **id**:`[a-z0-9][a-z0-9-]{2,63}`,且书包里的 id 必须带前缀:任何人自己做的 `u-<名>-<8 位随机十六进制>`,站点管理员书房的 `g-<名>`。**不带前缀的 id 留给书桌内置的官方典籍**(`daodejing` `lunyu` `sunzi` `guiguzi` `zhuangzi` `yijing`…),书包用了校验器报错。同一本书重出**不换 id**,只加 `revision`——阅读进度、划线按 id 记。
- `chapters[].no` 从 1 连续;`file` 必须存在;`minutes` 可无(书桌按字数估)。
- 章文件以 `chapters[].file` 为准(书桌按它打开);它必须按约定写成 `chapters/` + 章号补零到三位 + `.json`,校验器核这条约定,不合即报错。
- `chapters[].summary` 可无,≤ 80 字、一行(不含换行);文集宜每篇都写,书桌列目录时不必打开每个章文件。
- `head`(章题头图)与 `banner` 建议横版 3:2,`cover` 建议竖版 2:3;比例偏差超过 5% 校验器提示(不报错)。
- `theme` 的 `accent` `accent2` `paper` 可以只给其中几项,缺的用书桌默认色。

## 3 · 章文件

```jsonc
{
  "no": 1,
  "title": "肩胛骨先动",
  // —— 典籍层(kind = classic 必有,其余不许有)——
  "segs": [
    { "o": "原文一段", "t": "译文(可无)", "label": "段名(可无)",
      "n": [ { "k": "被注的词", "d": "一句话释义(≤ 40 字)", "x": "展开(可无,40–150 字)", "r": "读音(可无)" } ] }
  ],
  "yanyi": ["章后的短延伸,一段一项(可无)"],
  // —— 文章层(book / collection 必有;classic 可有,即「深读」)——
  "article": {
    "title": "可无,缺则用章题", "subtitle": "可无", "idea": "一句话中心(可无,≤ 200 字)",
    "blocks": [ … ]
  }
}
```

- 注 `n`:`k` 必须是该段 `o` 的精确子串;同段各条按首次出现位置互不重叠。
- 典籍的 `o` 是底本原文:**一个字不改**,来源在 `source` 里交代。

### 块(blocks)

文字里只有三种行内记号:`**加粗**`(成对)、`` `等宽` ``、`[文字](https://…)` 链接(只许 https,点了先问再用系统浏览器打开)。别的记号按字面显示。

| `t` | 字段 | 说明 |
|---|---|---|
| `lead` | `x` | 导语 |
| `h2` / `h3` | `x` | 小标题(两级) |
| `p` | `x` | 正文段 |
| `quote` | `o` `tr?` 或 `x` `by?` | 引文,两种形状取其一:原文式 `o`(必有)+ `tr` 译文(可无);一般式 `x` 引的话(必有)+ `by` 出处(可无)。`o` 与 `x` 不许同时出现,`tr` 只配 `o`、`by` 只配 `x` |
| `callout` | `tone` `label?` `items[]` | 提示框。tone:`note` `tip` `warn` |
| `pull` | `x` | 金句(一章至多 1 处) |
| `steps` | `items[]` | 有先后的步骤 |
| `list` | `ordered` `items[]` | 列举 |
| `outline` | `items[]` | 多级提纲 / 思想脑图。每项 `{x, children?}`,最多四层 |
| `fig` | `fig` `cap?` | 图解:结构化数据(对比 / 列举 / 流程 / 结构 / 时间线 / 表格 / 卦画 / 方位 / 金句卡),由书桌用原生版式画。字段见附录 A 与 `schema/fig.json` |
| `img` | `src` `alt` `cap?` `w` `h` | 图片。`w` `h` 必有,是文件的像素尺寸(排版占位用,须与文件一致) |
| `video` | `src` `poster` `cap?` `w` `h` `sec` `loop?` `sound?` | 视频 / 动图。`w` `h` 必有,同上。默认循环、静音、进入屏幕自动播,点一下暂停;`sound: true` 的不自动播 |
| `code` | `x` `lang?` | 代码或等宽文字 |
| `divider` | — | 分隔 |
| `refs` | `items[]` | 文末出处、参考 |

- 每章至少一个 `p` 或 `lead`;空块不许有。
- 不认识的 `t` 书桌会跳过(以后加新块不破旧版本),但校验器当错误报——照标准写的包里不该有。

### 字数怎么数

书桌、网站、工具说「多少字」都按同一条规则(核心库导出 `countChars`):只数字母、数字与汉字(Unicode `\p{L}` `\p{N}`),不数标点、空白与 `**` 一类记号。
- 典籍:数各章 `segs[].o`(只数原文);深读文章另计为「文章字数」。
- 现代书 / 文集:数文章里 `lead` `h2` `h3` `p` `quote` `callout` `pull` `steps` `list` `outline` `refs` 的文字;图注 `cap`、`alt`、`code`、图解里的字不计。

## 4 · 媒体

- 图片:`.jpg` `.png` `.webp`(写 `.jpg`,不用 `.jpeg`);长边 ≤ 4096。照片用 jpg,线条图用 png / webp。
- **动图一律转成视频**:`.mp4`(H.264,yuv420p,`+faststart`),长边 ≤ 1280,≤ 60 秒,无声或 AAC。GIF 不进包——同样的画面,GIF 往往大十倍以上。校验器带一条转换命令:`deskbook.mjs gif2mp4 a.gif`(需本机有 ffmpeg),同时出一张封面图 `poster`(与视频同名加 `-poster.jpg`,如 `media/a.mp4` → `media/a-poster.jpg`)。
- 每个 `img` / `video` 块引用的文件必须在包里;包里没人引用的媒体校验器会提示。
- 封面、题图、章题头图**不带文字**(书名由书桌用字体排上去)。

## 5 · 文字口径(做书的人要守的)

1. **版权**。`source.type = digest`(讲别人的书)时:全文绝不进包,文章是自己的话;直接引用每条 ≤ 100 字、每章 ≤ 16 条——`quote` 块、`pull` 金句、`fig` 金句卡(`kind: quote` 的 `text`)都算引用,一并计数;不得靠拼引文还原原书;不用出版社的封面与插图。校验器按这两个数卡。
2. **典籍**:原文取通行底本并在 `source.note` 写明;译注讲训诂、思想、史实,有争议并陈不裁断。
3. **不编造出处**。拿不准的引文、年代、数据不写,或明说「未能核实」。
4. 一章一个中心,先说结论再展开;图解与动图是为了讲清一件事,不为装饰。

## 6 · 红线与声明

| `disclaimer` | 什么时候必须带 | 书桌显示 | 内容上的约束 |
|---|---|---|---|
| `medical` | 讲医学、养生、健身、营养、心理治疗 | 书的首页与每章开头:「本书为知识研习,不构成医疗建议;身体不适请就医」 | 不给诊断、处方、剂量;不承诺疗效;健身动作写明量力而行 |
| `divination` | 讲命理、占卜、风水、相术 | 「本书为文化与文献研习,不作预测与决断依据」 | 讲「书里怎么说、为什么这么说」,不替人断命,不下吉凶断语 |

- `disclaimer` 可以是一个值,也可以是数组:同时讲两类的书写 `["medical", "divination"]`;自写的一句也可以放进数组(`["medical", "本书另有……"]`),书桌逐条显示。
- 校验器:`category` / `tags` 命中上述领域而没带对应声明,报错;两个领域都命中,两条声明都要带。其余题材不需要声明。

## 7 · 工具

`deskbook.mjs`(Node 18+,单文件,无依赖):

```
node deskbook.mjs init <目录> --kind book --title "…"     # 起一个骨架
node deskbook.mjs validate <目录 | 书包>                    # 校验:结构、引用、上限、口径上的硬数、声明
node deskbook.mjs pack <目录> [-o 书名.deskbook]            # 校验通过后打包
node deskbook.mjs unpack <书包> [-o 目录]
node deskbook.mjs gif2mp4 <a.gif> [-o media/a.mp4]         # 动图转视频 + 封面图(需 ffmpeg)
```

校验不过不打包。错误信息指到「哪个文件、哪一块、为什么」。

## 8 · 书怎么到书桌上

| 来路 | 谁能看到 | 怎么放 |
|---|---|---|
| 官方典籍 | 所有人 | 随观象网站托管(`/desk/v1/`),书桌的「添书」里就有 |
| 书房 | 只有管理员账号 | 对象存储。管理员在观象网站的书房上传页上传 `.deskbook`(网站 `/books` 下,仅管理员可见);书桌的「添书」里,管理员多一栏「书房」,按 `category` 分栏 |
| 自己导入 | 只在导入的那台设备上 | 把 `.deskbook` 传到手机(隔空投送、文件、分享菜单、或粘贴一个 https 链接),用书桌打开。**不上传** |

- 自己导入的书可以再原样分享出去(还是一个 `.deskbook`);划线与批注可以导出成 Markdown。
- 阅读进度、时长、划线照常跟账号同步(按书的 `id`),书本身不同步:换一台设备要再导入一次。
- 书桌里「我的 → 自定义导入」是这份标准的入口:讲三步怎么做、给标准与工具的下载、导入按钮。

## 9 · 版本

- `version: 1`。以后只加不改:加字段、加块类型、加 `fig` 的 kind;书桌遇到比自己新的 `version` 会提示升级 App,而不是硬读。
- 本标准、结构定义、校验器、做书用的 skill 都公开在 `https://hexa.gavin.pub/desk/standard/`。
