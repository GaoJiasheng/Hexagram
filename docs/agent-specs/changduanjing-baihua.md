## 取原文(硬规矩:脚本切片,严禁手打)
```python
import json,re
cl=json.load(open('/Users/gavin/work/hexagram/src/data/moulue/classics/changduanjing.json'))
def piece(key):
    g,o=map(int,key.split('-'))
    c=[x for x in cl['chapters'] if x['no']==g][0]
    h=[i for i,p in enumerate(c['paragraphs']) if re.fullmatch(r'《[^》]+》',p['original'].strip())]
    s=h[o-1]; e=h[o] if o<len(h) else len(c['paragraphs'])
    return c['paragraphs'][s:e]     # [0] 是篇题段
```
`quote.original` 必须是**本篇**原文的精确连续子串。

## 本书特殊之处(前几波挖出来的,务必沿用)
1. **括号夹注常不是赵蕤的按语,而是他从所引原书正文里删掉的部分**——先判归属再落笔。
   已坐实的例子:9-6 整段括号实为《韩非子·难三》原文;9-17「世治则小人守正」实为
   《文子》被《淮南子》剖开的后半截;10-x 几处反切音注疑为《汉书》颜注窜入正文。
2. **杂纂体**:大段引《老子》《荀子》《韩非子》《汉书》《六韬》《孙子》等再加按语。
   讲清「他引了谁、为什么引、他自己主张什么」,比逐句翻译有用。
3. **站内有的书一律 grep 对读,如实标异文、不代改**。已发现三类:
   - **唐讳指纹**(避太宗讳「民→人」、避高宗讳「治→理」),已在多篇坐实;
     9-7 更出现「同篇内一处避讳、一处未避」——**替换不彻底**,断代证据更硬
   - **引书被改到变味**:《八说》「离世遁上」→「离俗遁世」(锋芒磨钝)、
     孟子「亦终必亡而已矣」被删
   - **文本硬伤**:10-8 注文把「交地」「衢地」处置对调、与正文自相矛盾;
     10-2 引孙子「兵无选锋」误作「先锋」;10-10 引孙子三句独漏「非仁义不能使间」
4. **底本引号不统一**:卷八用「」,**卷十正文用弯引号(全卷 193 处)**。
   成品要求无弯引号,故 `quote.original` 照原样保留、**自撰文字与 translation 一律「」**;
   取 quote 时优先选不含引号的连续片段。

## 红线(谋略组·真书)
《长短经》是**唐人赵蕤真作**,不是《天下无谋》那五部托名伪书,**不套伪书批判框架**。
取**思想史与治国史视角**:
- 如实呈现其识人、用人、治乱、权变之论,讲清唐代的问题意识
- **绝不作现代政治影射、绝不作职场/管理权术教程、绝不作成功学**
- 涉驭下、察相、诡信、兵制一类尤其要守:讲清古人在什么处境下这么想、**这套想法的
  限度在哪**,而不是包装成可照搬的技巧。重点是**看穿而非教用**
- 卷十兵制条目**绝不写成可用的兵法实操或现代竞争策略**;兵阴阳(望气、时日)只作
  唐代知识结构的史料,**不作有效性主张**
- 史事以站内可核者为准;赵蕤所述无从坐实者,标明是他的转述
