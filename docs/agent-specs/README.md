# Agent 作业规格(共用 SPEC)

批量内容生产时派给 agent 的共用规格。**放在仓库里而不是 scratchpad**——
scratchpad 被系统清过一次,规格与未合并的分片一起没了,只能凭记忆重建。

派活时把这里的文件路径给 agent 让它先读,内容与 scratchpad 副本保持一致即可。

| 文件 | 用于 |
|---|---|
| `shijing-baihua.md` | 《诗经》诗级白话(键「组-序」) |
| `changduanjing-baihua.md` | 《长短经》篇级白话(键「卷-篇序」) |
| `batch-production-playbook.md` | **批量生产实战手册**——并发编排/合并校验/内容质量/红线守法,每条都注明是怎么踩出来的 |

**这套流程的通用铁律**(每份 SPEC 里都写着,此处汇总备查):
1. **一篇写完立刻落盘**,不许攒到最后——中断时已完成的才不会丢
2. **一篇一个独立分片文件**,不写共享库——多 agent 并发零写竞争
3. **不许转包子 agent**——踩过:父 agent 转包后提前返回,产出没落到约定目录
4. **引文一律脚本切片,严禁手打**;引他篇他书作旁证**必须先 grep 站内原文坐实**
5. **归给「站内注疏」的训释必须真的核过注疏文件**,没收的明写「注疏未收、为注家通说」
6. **篇幅初稿常超,必须裁到上限内再交**
7. 主会话**逐片重验后才入库**,不采信 agent 自查;**攒一批就入库一批**,别等最后
