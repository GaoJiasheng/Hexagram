# 把「观象」做成手机 APP · 可行性 + 方案 + 分步 Plan + Token 估算

> 目的:评估把现有网站(React 19 + Vite SPA,纯前端,数据存 localStorage,**已是 PWA**)做成手机 APP 的可行性,给出分步计划与每步 token 消耗,供 owner 决策(Opus 跑 / MiniMax 跑)。

## 一、可行性结论:**高,且代价低**

这站的形态对「转 APP」极其友好:
- **纯前端**:无后端、数据只在 localStorage —— 打包进 APP 后**天然离线可用**(比网页版还稳)。
- **已经是 PWA**:`vite-plugin-pwa` 已生成 manifest + service worker + 离线 precache,**现在就能「添加到主屏幕」当 app 用**。
- **路由对单机友好**:`HOST_GROUPS` 域名逻辑在非配置域名(app 内是 localhost)自动退回路径分组 —— 和我们部署到 IP 那台一样,已验证可用。

→ 不需要重写。最优路径是**用现有 web 构建直接套壳**,而不是用 React Native 重做 UI(那等于重写全部组件/样式/SVG,几百万 token 起,不值)。

## 二、三条路线对比

| 路线 | 是什么 | 工作量 | 能上应用商店 | 推荐度 |
|---|---|---|---|---|
| **A. PWA 打磨** | 现有 PWA 加图标/启动屏/iOS meta,用户「加到主屏幕」 | 极小 | 否(但 iOS/安卓都能装到桌面、全屏、离线) | ⭐ 先做,免费即得 |
| **B. Capacitor 套壳** | 把 `dist/` 包进原生壳(WebView),出真正的 .ipa/.apk | 小-中 | **是**(App Store + Google Play) | ⭐⭐⭐ 主推 |
| C. React Native 重写 | 用 RN 重做 UI | 巨大(近乎重写) | 是 | ✗ 不值 |

**主推 B(Capacitor)**:复用 100% 现有 web 代码,只加一层原生壳 + 少量适配。一套代码出 iOS + 安卓。

## 三、真正的瓶颈不是 token,是「原生环境 + 账号 + 审核」

这点要先说清,因为它影响「值不值得做」远大于模型选择:
- **iOS**:必须有 **Mac + Xcode**;上架要 **Apple Developer 账号($99/年)**;App Store 人工审核(1–3 天,可能打回)。
- **安卓**:要 Android Studio + 签名 keystore;上架 **Google Play Console($25 一次性)**;审核较松。
- 这些**账号注册、签名证书、真机调试、商店提交**是**人工 GUI 操作 + 等待**,任何模型都替不了,得你来做(我能逐步带你操作、写配置、修 bug)。

> 一句话:**token 花费很小(全程 ~1–2.5M,比一次白话内容跑〔30M+〕小得多),模型选谁差别不大;真正的成本是 Apple 账号、一台 Mac、和商店审核周期。**

## 四、分步 Plan + 每步 Token 估算 + 建议模型

token = agent 端 input+output 合计的**粗估区间**(含读码、改码、迭代调试)。「机械」步骤 MiniMax 足够;「需推理/调试」步骤 Opus 省迭代。

### 阶段 0 · PWA 打磨(可独立交付,先吃免费午餐)
| 步 | 内容 | Token | 模型 |
|---|---|---|---|
| 0.1 | iOS meta(`apple-mobile-web-app-capable`/状态栏样式)、manifest 补全、启动屏占位 | 60–120K | MiniMax |
| 0.2 | 站内「安装到主屏幕」引导 UI(iOS 分享→加到主屏;安卓 beforeinstallprompt) | 80–150K | MiniMax |
| 0.3 | 真机走查(iOS Safari / 安卓 Chrome 加桌面、全屏、离线) | 40–80K | 任意 |
| **小计** | **可独立上线,零商店依赖** | **~0.2–0.35M** | |

### 阶段 1 · Capacitor 接入(出可装的壳)
| 步 | 内容 | Token | 模型 |
|---|---|---|---|
| 1.1 | 装 `@capacitor/core|cli|ios|android`、`cap init`、配 `capacitor.config`(webDir=dist, appId, appName) | 80–150K | MiniMax |
| 1.2 | `cap add ios/android` + 首次 `cap sync`,跑通空壳加载 dist | 100–200K | 混合 |
| **小计** | | **~0.2–0.35M** | |

### 阶段 2 · Web 代码适配原生(真正的工程,Opus 价值最高)
| 步 | 内容 | Token | 模型 |
|---|---|---|---|
| 2.1 | 原生内**关掉 service worker**(SW 与 Capacitor 本地服务会打架),按环境条件注册 | 80–150K | Opus |
| 2.2 | 安全区(刘海/底部条)`env(safe-area-inset-*)`、状态栏插件 `@capacitor/status-bar` 配色 | 120–250K | Opus |
| 2.3 | 安卓硬件返回键、启动屏 `@capacitor/splash-screen`、外链用系统浏览器打开 | 100–200K | Opus |
| 2.4 | 路由/深链在 WebView 下走查(BrowserRouter 行为)、门户整页跳转改 SPA(顺带修你说的「跳转不太对」观感) | 100–200K | Opus |
| 2.5 | 真机/模拟器跑各页,修 WebView 专属 bug(字体、滚动、createPortal 浮层等) | 200–500K | Opus |
| **小计** | | **~0.6–1.3M** | |

### 阶段 3 · 图标 / 启动屏 / 品牌(需要一张 1024px 源图)
| 步 | 内容 | Token | 模型 |
|---|---|---|---|
| 3.1 | `@capacitor/assets` 从源图一键生成全尺寸图标/启动屏并接入 | 80–150K | MiniMax |
| **小计** | | **~0.1–0.15M** | |

### 阶段 4 · 构建与真机调试(大量是你侧 GUI 操作)
| 步 | 内容 | Token | 模型 |
|---|---|---|---|
| 4.1 | iOS:Xcode 签名、模拟器 + 真机跑、修构建/运行错 | 200–500K | Opus |
| 4.2 | 安卓:Android Studio、keystore、模拟器 + 真机跑、修错 | 150–400K | Opus |
| **小计** | (账号/签名/点 Xcode 是你做,我带 + 修码) | **~0.35–0.9M** | |

### 阶段 5 · 上架(几乎全是人工 + 等审核)
| 步 | 内容 | Token | 模型 |

| 5.1 | App Store / Play 商店元数据、隐私声明、截图准备(我帮起草,你提交) | 100–300K | 混合 |
| 5.2 | 提交 + 审核往返(等待 1–3 天,可能打回改) | 50–200K | 混合 |

## 五、总量与决策建议

| 目标 | 累计 Token(agent 端) | 现实周期 |
|---|---|---|
| **只做 PWA(阶段 0)** | **~0.2–0.35M** | 半天,无账号依赖 |
| **出可装的双端 app(阶段 0–4,未上架)** | **~1.5–3M** | 几天(含你配 Xcode/真机) |
| **上架 App Store + Google Play(全程)** | **~1.7–3.5M** | 1–2 周(主要等审核 + 账号) |

**模型取舍**:
- **机械步骤**(阶段 0/1/3、商店元数据):MiniMax 完全够,省钱。
- **适配 + 调试步骤**(阶段 2/4):**建议 Opus** —— WebView 专属 bug、构建报错、条件逻辑,猜错一次就是一轮迭代,Opus 收敛快、总账反而省。
- **但**:全程 token 总量(~3M)只相当于一次中型白话内容跑,**模型成本不是主要矛盾**;真正决定「做不做」的是你愿不愿意搞 Apple 账号($99/年)+ 用 Mac/Xcode + 等商店审核。

## 六、我的建议(分阶段、可叫停)

1. **先做阶段 0(PWA 打磨)** —— 几乎免费,做完你立刻能在 iPhone/安卓「加到主屏幕」当 app 用、离线可读。**先验证你是否真需要上商店**。
2. 若确实要进 App Store / Google Play → 上 **Capacitor(阶段 1–4)**,我带你配环境、改码、调真机。
3. 上架(阶段 5)按需,主要是你这边的账号 + 提交动作。

> 决策点:**只要「能装到手机、离线用、像 app」→ 阶段 0 就够,几乎不花 token。要「应用商店里能搜到下载」→ 才需要 Capacitor 全程 + Apple/Google 账号。**
