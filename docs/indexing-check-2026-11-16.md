一句话:**谷歌看起来一页都没收;必应只收了首页,而且是几个月前的快照;内页(五千多个章页)两边都没看到。**

## 站这一边我核过、没有问题的

- 爬虫访问章页拿到的是 200,带正确的标题(「道德经 一章 原文 · 译文 · 注释 · 道藏研读」)、canonical 和正文;没有 noindex(noindex 只挂在 `/books` 与 `/content/books`)。
- `robots.txt` 放行全站(只挡 `/books` `/me`),指向 `sitemap.xml`;站点地图索引下 17 个分站文件都能取到,带 lastmod。
- 首页里谷歌和必应的站长验证标签都在(`google-site-verification`、`msvalidate.01`)。
- IndexNow 密钥文件在线;最近一次有实际推送是 10-15(5241 条),之后几次发版内容页没变,所以是「待推 0 条」。

所以问题不像是站点把爬虫挡在了门外,更像是**搜索引擎还没把这个站排进抓取队列,或者抓了没编入索引**。新域名、五千多页、外链几乎为零的站,这种情况常见。

## 11-17 补记:站点这一边其实有一处硬伤,已修(待上线)

上面说「站这一边没有问题」,不全对。给爬虫的 HTML 里**一条站内链接都没有**(正文只是一个 `<p>`),首页对爬虫是空壳。
页与页之间没有链接关系可循,五千多页只能靠 sitemap 被发现——对一个没有外链的新站,这很可能就是谷歌迟迟不收的原因之一。
现在每页都带面包屑与站内链接(首页 → 各组 → 各书 → 各章 → 上一章 / 下一章 / 白话),索引里每一页都至少被另一页链到。
上线后仍要你在 Search Console 看下面三处;若站点地图已提交,可对首页点一次「请求编入索引」,让它重新顺着链接爬。

## 要你看的(五分钟)

1. **Google Search Console → 编制索引 → 网页**:看「已编入索引」是多少,「未编入索引」的原因里哪一类最多(「已发现 - 尚未编入索引」是还没来抓;「已抓取 - 尚未编入索引」是抓了但没收)。
2. **Google Search Console → 站点地图**:`sitemap.xml` 是否提交过、状态是不是「成功」、发现了多少网址。没提交过就提交一次。
3. **Bing Webmaster Tools → 站点地图 与 URL 检查**:同样看一眼。

把这三处的数字或截图发我,我按结果对症处理。

## 之后我能做的(看了数据再定)

- 「已发现未抓取」为主:说明缺的是外部入口。这正是推广第三档(社区首发帖、导航站、列表)要解决的事,稿子在 `docs/promotion-drafts.md`。
- 「已抓取未收录」为主:说明谷歌嫌页面之间太像或太薄。可以做的有:章页给爬虫的正文再加厚(现在只注入了一部分)、目录页和组首页补内链、合并过短的页。
- 站点地图没提交 / 报错:我按报错修。
- 必应首页摘要是旧的:首页描述早已更新,等它重抓;也可以在 Bing Webmaster 里对首页点一次「请求编入索引」。
