## 0. 立意与铁律(owner 拍板,最高约束)

收录 **《天下无谋·秘卷八书》**(马树全编译的托名谋略文丛:罗织经、小人经〔荣枯鉴〕、度心术、权谋术〔权谋残卷〕、守弱学、止学、解厄鉴 等)。**这批书与易/道/儒/佛/诸子/中医的传世正典性质不同**——多为后人托名或现代伪托,真伪存疑、不入正史书目。故本组**自成一格、显著框注**,取**文献批判与思想史视角**,非处世权术教程:

1. **真伪显著标注**:每书题解、书架卡片均显著标「**托名·真伪存疑**」徽标;authorNote 讲清考辨(托名何人、最早见于何时、学界存疑理由),不冒充传世正典。
2. **视角**:译文平实直译;注疏作字词训诂;**延伸讲文献批判与思想史**——这类书何时出现、为何托名、映照什么世态人心(如乱世权术之书的流行心理),**不作处世权术/厚黑教程式发挥、不教人构陷御心**(类比诸子「不作权术教程」、佛「不宣化」)。
3. **前提:维基文库有原文**。原文一律取维基文库可考本(**严禁手写**)。**维基没有的书,按项目规矩不收录**(或仅做脱离 corpus 的「评述介绍」页,不充经文)。可行书目以 agent 核实结果为准。

## 3. 工序(对标 corpus + 真伪框注层)

通用七步同诸子/中医:config 切片 → 原文录入(严禁手改)→ 全译 → 锚定注疏 → 篇/章延伸 → authorNote → check-data。本组特殊:
- **题解显著「托名·真伪存疑」**(ScriptureShelf/CorpusTextPage 加可选 `dubious` 徽标,仅本组开启)。
- **延伸=文献批判+思想史**(何时出现/为何托名/映照世态),守 §0 不作权术教程。
- 体量小(每书多为短篇格言体,数百至千余字),并发 workflow 一两批即可。

## 4. 验收
- 每批 check-data 零失败;`/moulue` 走查;跨组零链接。
- **框注专项**:逐书确认题解有「真伪存疑」标注、延伸无处世权术教程式发挥、authorNote 讲清考辨。
- 完书 status→done、发版。
