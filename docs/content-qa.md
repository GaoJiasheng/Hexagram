## 观察
- **机器装配的两类系统性瑕疵**:① 超长 note 句读截断留孤立逗号(jingangjing 三条);② 相邻段译文串接污染(tanjing 一处)。这两类可程序化排查全库(扫 note 尾逗号 / translation 含 `', '`)。
- **谋略组延伸的「托名作者朝代」最易错**(杨慎被作汉末/清,冯道被作宋,罗织/小人经混淆)——伪书考据本就绕,且我引入了一处。建议谋略延伸的撰人朝代统一复核。
- 译文层错误少且多为个别字词(尺六寸 / 律历 / 无不及),非系统性。
