# 「观象」八期 — 道藏→易经桥 v8.0

> 日期:2026-06-12 · 设计:Fable · 交付对象:Fable(实现)
> 兑现 v4 §3.7 预留的「与易经模块的桥(参同契/阴符经)」:两边内容已齐(v1.6.0),条件满足。
> **这是「模块不互链」规则的唯一例外**:桥仅在道藏侧出现、单向指向易经,易经侧零改动、零反向链接;门户仍是唯一的模块切换点。

## 1. 形态

桥不是正文里的裸链接,而是**挂在锚定注疏气泡里的跳转项**:参同契/阴符经原文中的卦名(乾坤坎离、十二消息、值日卦…)作为锚定条目,悬停/点按出气泡,气泡尾部多一行「《周易》第N卦·名 →」链接,点击进入易经卦详情页(主题随路由自动切回朱砂)。这样保持正文视觉统一(仍是注疏点状下划线),且桥点全部人工审定、零误报。

## 2. 数据(zhushi-anchored 条目扩展)

道藏注疏条目新增**可选**字段,与 note 可并存、亦可单独成条(纯桥条目可无 note):

| 字段 | 说明 |
|---|---|
| `hex` | 1–64,链至 `/hexagram/:id`,链接文案自动生成「《周易》第N卦·名 →」 |
| `to` + `label` | 任意易经路由的兜底(本期仅阴符经「八卦甲子」→ `/hexagrams` 用到) |

规则:**仅道藏侧文件可用**(易经 zhushi-anchored 禁用,check-data 强制);每个卦名只链该段首次出现;桥条目不计入注疏 0–4 条编辑上限(十二消息整组放行),但不得与既有注疏锚点重叠(沿用区间校验)。

## 3. 实现

- `daoAnchored.js` resolve 时把 hex/to 解析为 `qiao: { to, label }`(hex 经易经数据取卦名,纯代码复用,不构成 UI 互链);
- `ZhuTerm`(AnnotatedText)当 `entry.qiao` 存在时,气泡尾部渲染 `<Link>`;条目无 note 时气泡只显示词头+链接;
- check-data:hex 必须 1–64;易经侧条目出现 hex/to 即报错;无 note 的条目须有 hex/to(原"缺 note"校验放宽至此);
- CSS:`.zhushi__qiao` 链接行,沿用主题色。

## 4. 桥点范围(批次 2 审定,宁缺毋滥)

- **参同契**:大易总叙(乾坤坎离屯蒙)、圣人上观(月相纳甲:震兑乾巽艮坤、复卦)、龙虎两弦(兑艮)、阴阳精气/男女相须(乾坤坎离)、晦朔合符(六卦月相)、爻变功用(十二消息卦全组,媾=姤 出注)、日月悬象(震来受符,挂既有条目)。
- **阴符经**:「八卦甲子」→ 六十四卦总览(含八宫视图)。
- 其余四部**无桥**(无卦象内容,防蔓延)。
