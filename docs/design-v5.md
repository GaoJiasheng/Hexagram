## 2. 数据 `src/data/yijing/zhushi-anchored/`

人工内容,直接维护(与 zhushi.json 同性质,不走 fetch-data)。按文本分文件:

- `hexagrams.json` — 卦系传文:

```json
{
  "3": {
    "tuan":    [ { "term": "盈", "note": "充满。雷雨之动满盈,言阴阳始交、声势充塞。" } ],
    "daxiang": [ { "term": "经纶", "note": "整理丝缕,引申为筹划治理。", "source": "朱熹《周易本义》" } ],
    "xiaoxiang": {
      "1": [ { "term": "磐桓", "ref": true } ],
      "6": [ { "term": "泣血涟如", "n": 1, "note": "泣血,泣极而血;涟如,泪流不断貌。" } ]
    },
    "wenyan": { "0": [ ... ] }
  }
}
```

- `xici-shang.json` / `xici-xia.json` / `shuogua.json` / `xugua.json` / `zagua.json` — 经传:

```json
{ "5": { "0": [ { "term": "藏诸用", "note": "把功用隐藏于无形。诸,之于。" } ] } }
```

寻址约定:卦 id 与章号(chapter.no)用字符串数字;`xiaoxiang` 键为爻位 `"1"`–`"6"` 与 `"use"`(用九/用六);`wenyan` 与经传段落键为 paragraphs 数组下标(0 起)。

条目字段:

| 字段 | 必填 | 说明 |
|---|---|---|
| term | 是 | 锚定词,必须与该段原文逐字一致(含全角标点时不取标点) |
| n | 否 | 第几次出现,默认 1 |
| note | ref 为真时省 | 白话训诂,≤40 字 |
| reading | 否 | 生僻字注音(拼音) |
| source | 否 | 出处,程朱孔为主 |
| ref | 否 | true 时复用全局 zhushi.json 同名词条的 note/reading/source,单一来源不重复维护 |

## 3. 组件:AnnotatedText 锚定模式

- 新增 prop `anchors`(条目数组)。传入时走锚定模式:对每条解析第 n 次出现的位置,包成既有 ZhuTerm(气泡 UI、交互与词典模式完全一致);未传时维持词典模式,现有调用零改动。
- `ref: true` 的条目在组件侧(或装载层)解析为全局词条内容。
- ClassicText 透传 `anchors`;LineRow 为小象行新增 `xiaoxiangAnchors`;详情页按 hex.id 查 hexagrams.json 分发;经传阅读页按 book/章/段下标分发。
- 数据静态 import(与 hexagrams.json 同模式,gzip 后体量可接受;不做动态加载)。
- 气泡视口钳位(已随本稿落地):打开时测量,水平平移回视口内;顶部放不下翻到触发词下方(ZhuTerm useLayoutEffect + `.zhushi__popover--below`)。
- **密度控制是结构性的,不另设开关**:锚定条目只标第 n 次出现的那一处(词典模式才逐处命中),加之 §5 每段 0–4 条的编辑上限,系辞密集段的噪音问题在本方案下不存在;勿再加「仅首次出现」之类的死配置。

## 4. 校验(check-data 扩展)

逐条校验,任一不过即失败:

1. 寻址有效:卦 id/节名/爻位/章号/段下标必须存在于生成物;
2. 锚点命中:term 在目标原文中出现 ≥ n 次;
3. 同段锚定区间(按第 n 次出现解析后)互不重叠;
4. `ref: true` 的 term 必须存在于全局 zhushi.json;
5. note 缺失仅当 ref 为真。

另输出**覆盖率报告**(信息,非失败):各文本已注单元/总单元,精确到卦号、章号——这是断点续作的进度仪表。

## 5. 注疏内容风格(硬规范)

1. **训诂体,不复述译文**:释难字、通假、古义、名物、典故、特殊句式;整句意思是译文的事,注释不重复。
2. **宁缺毋滥**:每段 0–4 条;没有拦路词的段落留空,不硬注(序卦/杂卦的公式化短句预期大量留空)。
3. 选词标准——读者会卡住的词:生僻字(必填 reading)、通假字(「某,通某」)、古今异义、名物制度、人名典故。
4. note 一句话 ≤40 字,可用「某,某也」训诂句式;歧义取程朱主流;source 据实标(《周易正义》《伊川易传》《周易本义》),没把握不标、不杜撰。
5. 彖传/小象引经文术语(「利涉大川」「无咎」等已在全局词表者)一律 `ref: true`,不另写。
6. 全角标点转义规则照 CLAUDE.md 数据规则 4。
