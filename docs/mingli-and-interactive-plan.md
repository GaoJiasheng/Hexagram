| 路 | 利 | 弊 |
|---|---|---|

## 2. 学习路径:这些书按什么顺序读

这些书**不是平行的**,硬啃《三命通会》必然读不下去。通行的进阶次序,也是板块首页的骨架:

```
 前置知识(学堂 5 篇)
        ↓
《渊海子平》── 入门:术语、歌诀、基本法
        ↓
   ┌────┼────┐          ← 进阶三书,三条不同的路
《子平真诠》《滴天髓》《穷通宝鉴》
  格局      旺衰气势     调候
   └────┼────┘
        ↓
《三命通会》── 集大成:当百科查,不必通读
        ↓
 源头诸书 ── 想知道「这套东西从哪来的」再读
```

**最有意思的知识点在中间那一层**:同一个八字,《子平真诠》问「月令是什么格」、《滴天髓》问「日主强还是弱」、
《穷通宝鉴》问「生在几月、冷还是热」—— **三本书对同一个命例会给出不同的读法**。
这正是「家级导读」该写的那一篇(`school.json`:「子平法是怎么从一条路走成三条路的」),
也天然适合做成**争鸣式的三派对读**。

## 3. 怎么让这些书「学得进去」(不是又一个书架)

直接套读经站的管线,得到的是第 14 个书架 —— 对这些书**不够**。它们比诸子难读,难在三处,各配一件东西:

### 3.1 难点一:命例是天书 → **命例图**(本板块的招牌)

《滴天髓阐微》里约千处命例,原文长这样:`辛卯 丁酉 庚午 丙子`,后面跟一段分析。
**不会排盘的人看到的就是八个字**,分析说「丁火透干、坐下午火为根」—— 完全跟不上。

做法:管线识别四柱串 → 阅读器里渲染成**四柱图**(天干地支分行、五行着色、藏干展开、十神标注),
原文分析里提到的字,在图上对应高亮。

**这就是引擎的正确位置:不是让用户算自己,是让用户看懂书里的例子。**
站内已有完全同构的先例 —— 春秋筮例的「卦例图」(原文提到的卦,渲染成卦画 + 动爻)。

### 3.2 难点二:术语密度极高 → **概念索引**

十神、格局、用神、喜忌、通根、透干……每本书都在用,但各书说法有出入。
复用 `concepts.json` 的模式:**概念 → 各书哪一章讲它**(「用神」:真诠第八篇 / 滴天髓某章 / 渊海某节),
章末挂「义理互见」,术语走 `TermTip` 气泡。三处同源,现成机制。

### 3.3 难点三:没有前置知识根本进不了门 → **学堂(压缩为 5 篇)**

v1 的九篇学堂砍到五篇,定位从「主菜」改为「**读这些书之前必须会的**」:
① 干支与节气历法 ② 五行生克 ③ 四柱怎么排 ④ 十神 ⑤ 地支藏干与刑冲合害。
每篇配一个交互件(六十甲子盘 / 五行生克图 / 起柱口诀演示 / 十神关系图 / 十二支圆盘)+ `QuizCard`。
格局、旺衰、调候、大运 **不进学堂** —— 那是书里讲的,让书来讲。

### 3.4 四层内容照旧

原文 → 译文 + 注疏 → 每章延伸 → 白话深读,全套现成管线。另加两层导读:
每书一篇「前世今生」(书级)、全组一篇「一家之来路」(家级,即 §2 那篇三派分流)。

### 3.5 排盘台:降级为附属工具

保留,但从首屏撤下,放在学堂第 ③ 篇之后作「练手」—— 学完怎么排,自己排一个验证。输出止于结构。

## 4. 红线(一段话)

这些书**通篇是断语**(「此造必贵」「早年刑克」),处理办法站内早有成例 ——《本草经》的「主治」:
**原典照译,不删不讳;注疏、延伸、白话只作训诂与思想史,不替它背书、不教人套用。**
真伪如实(滴天髓/李虚中命书/玉照定真经皆依托,走 `caveat`)。写进 CLAUDE.md 作本组铁律「研习不断命」。

## 7. 其他板块的交互化盘点(v1 保留,未变)

**判据**:内容本身有结构(规则 / 时间 / 关系 / 流程)、现在却被压成线性文字的,收益最大。

| 优先 | 板块 | 被压扁的结构 | 交互形态 | 成本 |
