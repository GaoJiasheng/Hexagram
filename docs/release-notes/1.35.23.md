---REVIEW---
This update refines the tablet experience and redesigns the group home pages. Navigation now has directional page transitions and restores scroll position when going back; the tab bar remembers the last page of each section; light haptic feedback on tab and chapter selection (via the standard Capacitor Haptics plugin, UIImpactFeedbackGenerator); hardware-keyboard shortcuts on iPad; a two-column table-of-contents layout on wide screens. Seven group home pages now show a "continue reading" row, a suggested reading order, and links to the group's indexes. All content is bundled and works offline; no new permissions, no new data collection, no new third-party SDKs beyond the haptics plugin. Account creation remains optional. Test account unchanged.
