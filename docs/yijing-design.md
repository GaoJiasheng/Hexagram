## 1. 产品定位与设计原则

### 1.1 定位

一个供站主个人**研习易经**的网站。两大支柱能力:

- **原文解析**:六十四卦经文(卦辞、爻辞)+ 十翼(彖、象、文言、系辞、说卦、序卦、杂卦)的完整呈现、注译与结构化导航。
- **推演变化**:基于易理的确定性推演——卦的演化(动爻 → 变卦，以及互、错、综)与解卦(传统变占规则 + 爻位分析)。

它是**学习工具，不是算命网站**。所有"解卦"输出都呈现为"经文依据 + 传统断法 + 结构分析",语气克制，页脚常驻一行小字:"本站为个人学习用途，解读内容仅供研习参考"。

### 1.2 设计原则(五条，不可妥协)

1. **纸墨气质**:整站如一册安静的线装书。宣纸底、墨色字、朱砂点睛。任何一屏中朱砂色占比不超过 5%。
2. **经文至上**:原文永远是字号最大、对比最高的元素；译注是辅助层，可一键隐藏。
3. **结构可见**:易经的魅力在结构(爻位、卦变、错综互)。凡有结构关系处，必须可视化、可点击跳转，不能只用文字罗列。
4. **克制的动效**:动效只用于解释结构变化(如爻的阴阳翻转),不做装饰性动画。
5. **零等待**:纯静态资源，首屏即用。字体异步加载，加载前用系统宋体兜底，不允许白屏或布局跳动。

### 1.3 Do & Don't

| Do | Don't |
|---|---|
| 大量留白，细分割线 | 卡片阴影满屏、描边粗重 |
| 衬线字体(宋体系) | 默认无衬线黑体做正文 |
| 朱砂色只用于：动爻、当前激活态、印章 | 把朱砂当主题色大面积铺 |
| 自绘 SVG 卦画，全站统一组件 | 用 emoji、图片或 unicode 字符 ䷀ 当主要卦画(unicode 仅用于搜索结果等极小场景) |
| 页面切换 150ms 淡入 | 弹跳、视差、骨架屏闪烁 |
| 浏览器原生滚动 | 自定义滚动条、scroll-jacking |

| `--ink-faint` | `#A89F93` | `#6B6157` | 辅助说明、禁用 |

主题：亮 / 暗 / 跟随系统，存设置。切换入口在「我的 → 设置」及顶栏(桌面端，月亮/太阳细线图标)。

### 3.2 字体

```css
--font-serif: "Noto Serif SC", "Songti SC", "SimSun", serif;   /* 全站默认 */
--font-mono:  ui-monospace, monospace;                          /* 仅二进制/调试 */
```

- Noto Serif SC 通过 `<link>` 异步加载(weights: 400, 600),`font-display: swap`。
- **字号阶梯**(rem,根 16px):
  - 经文原文:1.25(列表内)/ 1.5(详情页卦辞爻辞)/ 1.75(详情页卦名旁提要不用，仅卦辞可到此档)
  - 卦名大字:2.5(详情页头部)
  - 正文/译文:1.0;辅助说明:0.875;微标注:0.75
- 经文阅读字号三档可调(0.9× / 1× / 1.15×),设置项 `fontScale`,只作用于经文区块。
- 行高：经文 1.9;译文正文 1.75。经文支持用户选中复制，不做任何禁用。

### 3.3 间距与形状

- 4px 网格。常用间距:8 / 12 / 16 / 24 / 40 / 64。
- 内容最大宽度：常规页 960px;阅读页(经传、卦详情经文区)正文栏 680px。
- 圆角：按钮与输入 4px;卡片 6px;印章 2px。
- 卡片:`--paper-raised` 底 + 1px `--line` 描边,**无阴影**;hover 时描边变 `--ink-faint`。
- 焦点态(键盘):2px `--ochre` 外描边，全站统一。

### 3.4 按钮

| 类型 | 样式 | 用途 |
|---|---|---|
| 主按钮 | `--ink` 底、`--paper` 字,hover 加深至纯黑/纯白 | 每屏至多一个(如「开始推演」) |
| 次按钮 | 透明底、1px `--ink-faint` 描边、`--ink` 字 | 常规操作 |
| 文字按钮 | 无底无框,`--azure` 字 | 行内动作、链接型 |
| 危险 | 文字按钮但 `--cinnabar` 字 | 删除笔记/历史 |

### 3.5 卦画绘制规范(全站最重要的图形元素)

SVG 绘制，自下而上为初爻 → 上爻(**爻序方向绝对不能错**)。

```
阳爻:  ━━━━━━━━━━━     一根通长矩形
阴爻:  ━━━━   ━━━━     两段矩形，中间留空，空隙宽 = 爻宽 × 0.18
```

| 尺寸 | 爻宽 | 爻高(粗) | 爻间距 | 用途 |
|---|---|---|---|---|
| sm | 40px | 5px | 5px | 矩阵格、列表、历史记录 |
| md | 72px | 8px | 8px | 卡片、推演结果区 |
| lg | 128px | 13px | 12px | 详情页头部、工作台 |

- 颜色：默认 `--ink`;**动爻整爻染 `--cinnabar`**,且爻右侧 8px 处加传统标记：阳动 `○`(九)、阴动 `✕`(六),同朱砂色，字号约爻高 1.2 倍。
- 交互态(仅 interactive 模式):hover 该爻底部出现 `--cinnabar-bg` 淡底条；光标 pointer;键盘可聚焦(每爻一个 focusable,`aria-label` 如"九三，阳爻，点击设为动爻")。
- **翻转动效**(阴阳互变，用于工作台与变卦演示):阳→阴，矩形从中点裂开向两侧收缩成两段；阴→阳，两段向中间合拢连成一根。时长 400ms,`cubic-bezier(0.25,0.1,0.25,1)`。整卦多爻变化时自下而上每爻延迟 60ms。`prefers-reduced-motion` 时直接切换无动画。
- 组件 `aria-label` 示例:"水雷屯，下震上坎，初九为动爻"。

### 3.6 卦名印章

详情页与卡片中，卦名可附一枚小印章(SVG):朱砂底白文，正方形，内放卦名(1–2 字),仅作装饰，出现频率克制(详情页头部 1 枚即可)。

## 5. 页面详细设计

### 5.1 首页 `/`

定位：每日入口 + 各功能分发。安静，不堆信息。

```
┌──────────────────────────────────────────────┐
│                                              │
│          观 象                                │   大字站名(可换),下一行小字
│   观其象而玩其辞，观其变而玩其占                   │   《系辞》引文,--ink-soft
│                                              │
│   [ 浏览六十四卦 ]   [ 开始推演 ]               │   主按钮 + 次按钮
│                                              │
├──────────────── 今日一卦 ─────────────────────┤
│  ┌────────────────────────────────────────┐  │
│  │  [md卦画]  谦 · 第十五卦  地山谦          │  │   整卡可点进详情
│  │  「谦谦君子，卑以自牧。」                  │  │   摘大象传或卦辞一句
│  └────────────────────────────────────────┘  │
├──────────────── 继续研习 ─────────────────────┤
│  (有 localStorage 记录时显示，最多 3 张小卡)     │
│  [上次推演：屯之比]  [上次阅读：系辞上·第四章]     │
│  [最近浏览：蒙卦]                               │
├──────────────── 四个入口 ─────────────────────┤
│  [原文研读]   [卦变推演]   [经传通读]   [八卦基础] │   2×2(移动端)/ 1×4(桌面)
│   六十四卦…    动爻变卦…    系辞说卦…    阴阳爻象…  │   卡片：标题+一行说明
└──────────────────────────────────────────────┘
```

- **今日一卦**:确定性算法 `hash(YYYY-MM-DD) % 64 + 1`(简单字符串 hash 即可),同一天全站一致。卡片右上角小字"今日一卦 · 六月十一"。
- **继续研习**:读 localStorage(最近推演、阅读进度、最近浏览卦),无记录则整个区块不渲染。
- 首页不放页脚以外的任何说明文字，保持空。

### 5.2 六十四卦总览 `/hexagrams`

顶部：标题「六十四卦」+ 视图切换分段控件 `[卦象矩阵 | 序卦次序]` + 右侧筛选。

**视图一：卦象矩阵(默认)** — 经典 8×8 上下卦组合表。

```
        下乾   下兑   下离   下震   下巽   下坎   下艮   下坤
 上乾  [乾]  [履]  [同人] [无妄] [姤]  [讼]  [遁]  [否]
 上兑  [夬]  [兑]  [革]  [随]  [大过] [困]  [咸]  [萃]
 ……(8 行，行列表头是 TrigramBadge)
```

- 每格:sm 卦画 + 卦名 + 卦序号(微字)。hover:描边变深 + 浮出一行卦辞首句(tooltip 样式，纸底细框)。点击进详情。
- 行/列表头 hover 时，整行/整列加 `--cinnabar-bg` 淡底——直观看到"同一经卦"的家族。
- 移动端：矩阵横向可滚(表头吸附),或自动降级为列表视图(实现选其一，推荐横向滚动 + 首列吸附)。

**视图二：序卦次序** — 1→64 列表,**两两一组**呈现(序卦"非覆即变"):

```
03 屯 [sm卦画]  ⇅综  [sm卦画] 蒙 04      ← 一对一行，中间标注 关系：综(倒转)或 错(乾坤、坎离等八对)
   「屯者，盈也…」序卦传该句小字摘录
```

- 这是教学性视图：让"上下经 + 非覆即变"的结构一眼可见。上经(1–30)/下经(31–64)之间插入一条分隔标题。

**筛选**(两个下拉，皆可空):「含上卦__」「含下卦__」，选中后矩阵高亮对应行列、列表过滤。

### 5.3 卦详情页 `/hexagram/:id`(原文解析的核心页面)

阅读型页面，正文栏 680px 居中，桌面端右侧悬浮一个 160px 小目录(锚点：卦辞/彖/象/六爻/文言/关联)。

**① 头部区**

```
┌──────────────────────────────────────────────┐
│   [lg 卦画·interactive]      屯  [印章]        │
│    (点击任一爻即时预览变卦)    zhūn · 第三卦      │
│                            ☵ 坎上 · ☳ 震下     │
│                            水雷屯|云雷，屯       │
│   ──────────────────────────────────────     │
│   错卦[鼎]  综卦[蒙]  互卦[剥]  宫[坎宫二世]      │   DerivationStrip,每项=文字按钮+悬浮sm卦画
│                                              │
│   [☆收藏]      [以此卦推演 →]                  │
└──────────────────────────────────────────────┘
```

- **头部卦画的轻交互**(本页招牌交互):点击某一爻，该爻以翻转动效变换阴阳，旁边淡入一张小浮卡:"九三动 → 变为 水火既济",点击浮卡跳到对应卦详情，点击别处或再点该爻还原。一次只允许一个爻处于预览态。这让"每一爻都通向另一卦"在阅读时随手可感。
- 「以此卦推演」跳 `/workbench?gua={id}`。

**② 卦辞区**(锚点：卦辞)

- `ClassicText`:原文大字(如「屯：元亨，利贞。勿用有攸往，利建侯。」),下方译文。
- 右上角小开关「译」：全局译文显示开关的就地入口(同步设置)。

**③ 彖传 / 大象传**(锚点：彖、象)

- 两个区块，小节标题「彖曰」「象曰」用 0.875rem `--ink-faint` 盖在原文上方。
- 默认展开；每块可折叠(标题行点击),折叠状态记忆到设置(全站统一，不按卦记)。

**④ 六爻区**(锚点：六爻)——本页信息密度最高处，逐爻一张 `LineRow`:

```
┌──────────────────────────────────────────────┐
│ 初九 ─────────────────────────  当位 · 应六四  │  ← 爻题 + 爻位标记(chips,0.75rem)
│ 磐桓，利居贞，利建侯。                            │  ← 爻辞,1.5rem
│ 象曰：虽磐桓，志行正也；以贵下贱，大得民也。          │  ← 小象,1rem,--ink-soft
│ 〔译〕徘徊难进，宜守正不动…                       │  ← 译文，受开关控制
└──────────────────────────────────────────────┘
```

- 排列顺序:**初爻在最上、上爻在最下**(随文本阅读习惯)。
- **联动**:hover/聚焦某张 LineRow 时，页面头部的 lg 卦画对应爻加 `--cinnabar-bg` 高亮；反之点击头部卦画某爻(非预览模式时长按?——不，保持单击=预览变卦，这里用)滚动定位:**目录中提供"六爻"锚点即可，不再给卦画加第二种点击语义**(一个元素只有一种点击行为)。
- 爻位标记 chips 的判定全自动(§6.4):`当位/失位`、`得中`(二、五)、`应六四/敌应`。中正兼备(六二、九五)时 chip 换成一枚 `--ochre` 描边的「中正」。
- 乾、坤两卦在上九/上六之后追加「用九/用六」区块，样式同 LineRow 但无爻位 chips。

**⑤ 文言传**(仅乾、坤；锚点：文言)— 折叠区块，默认折叠，内部按章节分段排版。

**⑥ 关联区**(锚点：关联)

- 「序卦」：引序卦传中本卦前后衔接句(如"物生必蒙，故受之以蒙"),其中相邻卦名是链接。
- 「杂卦」：引杂卦传该句。
- 底部 prev/next 通栏:`← 第二卦 坤` `第四卦 蒙 →`。

**⑦ 我的笔记** — `NoteEditor`,storageKey 按卦 id。占位文字:"记下你对此卦的理解…"。

## 6. 推演引擎(确定性规则，全部纯函数)

> 实现为 `src/features/yijing/engine/` 下的纯函数模块,**必须配套单元测试**(§10 验收含测试点)。

### 6.1 卦的表示

- 规范形:6 位二进制字符串,**自下而上**(下标 0 = 初爻),`1`=阳,`0`=阴。如屯 = `"100010"`。
- 经卦表(自下而上 3 位):

| 卦 | 符 | 二进制 | 自然 | 性情 | 家人 | 后天方位 |
|---|---|---|---|---|---|---|
| 乾 | ☰ | 111 | 天 | 健 | 父 | 西北 |
| 兑 | ☱ | 110 | 泽 | 悦 | 少女 | 西 |
| 离 | ☲ | 101 | 火 | 丽 | 中女 | 南 |
| 震 | ☳ | 100 | 雷 | 动 | 长男 | 东 |
| 巽 | ☴ | 011 | 风 | 入 | 长女 | 东南 |
| 坎 | ☵ | 010 | 水 | 陷 | 中男 | 北 |
| 艮 | ☶ | 001 | 山 | 止 | 少男 | 东北 |
| 坤 | ☷ | 000 | 地 | 顺 | 母 | 西南 |

- `binary → 卦序(1–64)` 用一张 Map(由 hexagrams.json 构建),所有推演输出经卦序回查数据。
- Unicode:卦字符 = `U+4DC0 + (卦序 − 1)`(䷀乾…䷿未济),仅用于搜索结果与导出文本。

### 6.2 卦变四法

| 推演 | 算法(对 binary) | 自检用例 |
|---|---|---|
| 变卦(之卦) | 翻转所有动爻位 | 屯(100010)初爻动 → 000010 = 比 |
| 互卦 | 新下卦 = 2,3,4 爻；新上卦 = 3,4,5 爻 | 屯 → 互 剥；乾坤的互卦是自身 |
| 错卦(旁通) | 每位取反 | 屯 ↔ 鼎；乾 ↔ 坤 |
| 综卦(覆) | 六位整体倒序 | 屯 ↔ 蒙；自综八卦：乾坤坎离颐大过中孚小过 |

### 6.3 变占规则(朱熹《易学启蒙》通行简表)

输入：本卦 + 动爻集合(0–6 个)。输出:`{ ruleName, ruleNote, primaryTexts[], secondaryTexts[] }`。

| 动爻数 | 取辞 | UI 主显 |
|---|---|---|
| 0 | 本卦卦辞(参大象) | 本卦卦辞 |
| 1 | 本卦该动爻爻辞 | 该爻辞 |
| 2 | 两动爻爻辞,**以上者为主** | 上位动爻爻辞为主卡，下位动爻爻辞列其后 |
| 3 | 本卦 + 变卦卦辞，本卦为贞、变卦为悔 | 两卦辞并列，标注贞/悔 |
| 4 | 变卦中**两不变爻**爻辞，以下者为主 | 变卦下位静爻爻辞为主 |
| 5 | 变卦中唯一不变爻爻辞 | 该爻辞 |
| 6 | 乾→用九、坤→用六；余卦用变卦卦辞 | 对应文本 |

`ruleNote` 为一句规则出处说明(如"依《易学启蒙》：二爻变者，以本卦二变爻之辞占，以上爻为主"),固定文案写在引擎里。

### 6.4 爻位分析(对任意爻位 n=1..6 与爻性)

- **当位**:阳爻居 1/3/5,阴爻居 2/4/6 → 当位，否则失位。
- **得中**:n=2(下卦中)或 n=5(上卦中)。九五/六二 = 既中且正。
- **相应**:配对 (1,4)(2,5)(3,6),两爻一阴一阳 → 相应；同性 → 敌应。
- **乘刚**:阴爻紧邻其下为阳爻 → 该阴爻"乘刚";**承阳**:阴爻紧邻其上为阳爻 → "承阳"。
- 文案模板(引擎内固定字典，示例):
  - 当位+相应:"{爻题}:{阴阳}居{奇偶}位(当位),与{对位爻题}相应——位正而有援。"
  - 失位+敌应:"{爻题}:{阴阳}居{奇偶}位(失位),与{对位爻题}敌应——位不正且乏应，宜慎。"
  - 得中追加:"居{上/下}卦之中，得中。" 中正兼备追加:"中正兼备，为一卦之善位。"
- 模板语气：陈述结构事实 + 极简引申,**不做吉凶断言**(不出现"大吉""凶险将至"类词)。

### 6.5 今日一卦

`seed = "YYYY-MM-DD"` 的简单 hash(如 djb2)`% 64 + 1`。无随机性，当日恒定。

## 9. 内容生产规范(给数据录入的硬性要求)

1. **原文以通行本(王弼本系统)为准**,简体中文、现代标点。卦名、爻题(初九/六二…)、用九用六必须逐字核对;**任何拿不准的字以中华书局通行排印本为准**。
2. 译文风格：平实白话，直译为主，一段原文对应一段译文;**不得出现**算命口吻("此卦大吉，必有横财"类)与现代心灵鸡汤；遇歧解取主流注疏(程颐、朱熹)其一即可，不并列。
3. `summary`(一句提要)≤14 字，中性概括卦义。
4. 数据完成后跑校验脚本(实现时写一个 `npm run check-data`):64 卦齐全、binary 唯一且与上下卦字段一致、每卦 6 爻齐全、乾坤含 extra、其余 extra 为 null、所有 original 字段非空。
