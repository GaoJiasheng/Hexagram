## 1. 经文字词注释层

### 1.1 目的与范围

译文解决"整句读不懂",注释层解决"单字什么意思、为何这样译"。范围:**卦辞与爻辞的原文**(详情页经文区);彖象传原文不挂(信息密度控制,译文已覆盖)。

### 1.2 数据 `src/data/yijing/zhushi.json`

人工内容,直接维护(与 glossary.json 同性质)。条目:

```json
{ "term": "元亨", "reading": null, "note": "大为亨通。元,大也;亨,通也。", "source": "程颐《伊川易传》" }
```

- 约 40 条,**长词优先**收录(「利涉大川」「利见大人」「无咎」「悔亡」先于「亨」「贞」单字),匹配时最长优先。
- note 一句话白话,可带训诂(「某,某也」);source 标注主要依据(程朱为主),可省。
- 首批词表:元亨利贞(及连用「元亨」「利贞」)、悔、吝、咎、无咎、孚、有孚、厉、眚、吉、凶、利涉大川、利见大人、利有攸往、有攸往、勿用、贞吉、贞凶、悔亡、无不利、征、征吉、征凶、亨、王假、君子、小人、大人、先甲后甲、密云不雨、其他高频实词酌补。

### 1.3 组件 `AnnotatedText`

- props: `text`(原文字符串)。对 text 做**最长优先扫描**,命中词渲染为带点状下划线的 span,悬停/点按出小气泡(term + note + source),交互行为与 TermTip 一致(hover 开、点击切换、Esc 关、外点关)。
- 不命中部分原样输出。注释气泡不链名词表(zhushi 与 glossary 是两套:一个释经文字词,一个释易学术语)。
- 挂载点:HexagramDetailPage 的卦辞原文、各爻爻辞原文。**译文行、彖象传不挂。**

## 2. 易学源流页 `/basics/yuanliu`(学堂第八篇)

时间线纵列,每节点:时代 | 人物/学派 | 一段白话(80–150字) | 关键词 chips。节点(定稿,实现照录):

1. 传说时代 · 伏羲画卦——观象于天、观法于地,始作八卦
2. 殷周之际 · 文王演易(传重卦、系卦辞),周公系爻辞——«周易»经文成形
3. 春秋 · 孔子赞易——传作十翼(彖象系辞文言说卦序卦杂卦),易由卜筮之书转为义理之书
4. 汉 · 象数易学——孟喜卦气、京房八宫纳甲、郑玄爻辰;易与历法灾异结合
5. 魏晋 · 王弼扫象——«周易注»以义理解易,「得意忘象」,确立通行本
6. 唐 · 孔颖达«周易正义»——官学定本,集汉魏注疏之成
7. 北宋 · 邵雍先天之学——先天图、皇极经世;周敦颐太极图说;图书之学兴起
8. 南宋 · 程颐«伊川易传»、朱熹«周易本义»——义理与象数合流,后世科举定本
9. 清以降 · 考据与出土——惠栋、焦循复汉易;帛书、竹简改写文本史(仅一句带过)

页尾注一句:「本页为研习线索,非学术史定论」。LEARN_TOPICS 注册 id `yuanliu`,quiz:false,usedKeys:null(只有「读」一层)。本页人物与本站功能呼应处(京房八宫、邵雍梅花/先天图、程朱译文取径)用普通文字提及,不强制加链接。

## 3. 多模块门户与道藏框架

### 3.1 信息架构

```
观象(站点)
├── 易经研习(默认模块)        现有全部路由不动:/ /hexagrams /workbench /classics /basics /me
└── 道藏研读(新模块)          /dao              模块首页(书架)
                              /dao/:slug        文本框架页 ×6
```

- `/` 仍是易经首页(不破坏现有链接与习惯);门户是覆盖层而非路由页。
- 模块判定:`location.pathname.startsWith('/dao')` → 道藏模块。

### 3.2 门户切换(ModulePortal)

- 触发:导航栏品牌印章右侧新增一枚小章「易 ⇄」(道藏模块下显示「道 ⇄」),点击打开**整屏覆盖门户**。
- 门户:纸色整屏,居中两张大卡——「易经研习」(简介:读卦·推演·学堂)与「道藏研读」(简介:道德经·南华·丹道诸经,标注「整理中」)。点卡片进对应模块首页;Esc/点空白关闭;当前模块卡片带「当前」角标。
- 这就是「网站之间切换」的体感来源之一;来源之二是 §3.4 的换肤。

### 3.3 模块化导航

- Nav 链接按模块渲染:易经模块为现有四项;道藏模块为「经典」(/dao)单项(框架期)。搜索按钮仅易经模块显示(搜索索引是易经数据)。
- MobileNav 同理:道藏模块下显示「经典 | 切换」两项(切换=开门户)。
- 页脚共用。

### 3.4 道藏模块视觉

- `app-shell` 在道藏模块下加类 `app-shell--dao`,以 CSS 变量覆盖换主色:`--cinnabar → 玄青(取 --azure 色值)`、`--cinnabar-bg` 同步。纸色、墨色、字体不变——同一张纸,换一方印。
- 品牌印章在道藏模块下显示「观道」。

### 3.5 文本注册表 `src/data/dao/texts.json`

```json
{ "slug": "daodejing", "title": "道德经", "alias": "老子·五千言", "era": "先秦", "attribution": "老子",
  "sections": 81, "sectionUnit": "章", "brief": "一句话题解", "status": "pending" }
```

六部(次序即书架次序):道德经(81章)、清静经(1卷)、太上感应篇(1篇)、庄子内篇(7篇)、阴符经(3章)、周易参同契(上中下3篇)。status: pending | partial | done。

### 3.6 页面框架

- **DaoHomePage(/dao)**:书架式列表,每部:题名(竖排感可用大字号衬线)+ 时代/托名 + 一句题解 + 「整理中」徽记;点击进框架页。
- **DaoTextPage(/dao/:slug)**:面包屑「← 道藏」;题名 + 时代/作者行 + 题解段;章节占位网格(sections 数量的灰格,不可点);EmptyState「经文整理中——录入后此处即为章节阅读」。slug 不存在 → 模块内 404。
- 阅读器、译注、检索等留待内容期,本期不做。

### 3.7 道藏模块的后续里程碑(本期不做,防蔓延)

数据管线(维基文库抓取+繁转简+校验)、章节阅读器(复用经传阅读器模式)、译注层、版本对照(王弼/帛书)、与易经模块的桥(参同契/阴符经)——桥也要等两边内容都齐,且只在道藏侧出现。
