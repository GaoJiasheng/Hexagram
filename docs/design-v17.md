## 0. 调性铁律(贯穿译·注·延,不可破)

**守「研习不宣化、不下吉凶 / 果报断语」**(对齐易经侧「禁算命口吻」)。佛站立意为**思想史与文献研习**,非信仰道场:

- 译文白话取经文字面义,不作劝信、不许愿、不演法门次第。
- 注疏作梵汉对音 / 名相训诂 / 通假,不判教、不立宗争优劣。
- 延伸讲思想与故事与源流(罗什译场、玄奘西行、慧能身世与南北宗、公案的思想史意义),**不渲染感应灵验、不下果报吉凶**。
- 参学术向注本择善而从:江味农《金刚经讲义》、印顺《般若经讲记》、丁福保《六祖坛经笺注》、郭朋校释——取其训诂与考据,舍其宗派判教。

## 2. 三经分书风格(在 §0 铁律、v6 §4–§5、v9 §4 之上)

- **心经**:260 字字字关要;译文取玄奘本直解,「色 / 空 / 五蕴 / 波罗蜜多」名相全入注疏(梵音 + 义),歧解(「度一切苦厄」是否罗什增)标出处。
- **金刚经**:罗什本遮诠句式(「所谓…即非…是名…」)直译保其反复,不强解通顺;「应无所住而生其心」「三千大千世界」「阿耨多罗三藐三菩提」入注;延伸讲译场与禅宗印心史,不演空观工夫。
- **坛经**:语录公案体直译,人名 / 偈颂 / 禅门术语(顿渐 / 无念 / 自性 / 行由)译文存原,注疏释之;敦煌本 / 宗宝本异文存疑处标明;延伸讲慧能身世、南北宗、坛经成书层累,**不作祖师崇拜叙述**。
