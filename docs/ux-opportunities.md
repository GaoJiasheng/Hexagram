# 全站易用性 / 功能性优化 roadmap(v1.25.0 后第三轮审查)

> 四片并发审查(发现性·读经核心·推演学堂·个人数据)汇总。这一轮找的不是 bug,是「能更好」的优化空间。
> owner 拍板:**全部按 Tier 推进(0→1→2),逐批 check-data/build/走查/发版**。

## 战略主线(四个 agent 收敛的结论)

全站功能与内容已厚,**最大体验落差:9 个读经站(占内容绝大部分)缺一个「个人层」**——既**不能记**(无收藏/笔记/划线),设置与「我的」也**对它们不可达**(点 ☯ 把人甩回易经站)。一快一慢两件事,共用一把 `corpus:slug:章:段` 锚:① 全站设置浮层(快赢,解决可达)② 读经站收藏/笔记(结构性,解决「能记」)。这把锚与「长章段号/分享深链」同源,一次地基四处收益。

## Tier 1 · 中等(需一点设计)

- 练习改「教练」:错题「只练刚才错的 N 题」+ 文案从「差一点」改鼓励
- 原文/译文对照模式(第三态:关 / 下方 / 左右对照)
- 注疏「本章一览」(章末/侧栏列全部注疏,替逐词悬停)
- 研习仪表盘(进度环 + 建议下一步 + 连续学习天数,时间戳已存)
- 读经逐章 ←→ 键 / 横滑翻页(移植易经卦页交互)
- 设置加行宽 / 默认译文开关
- 段落分享深链「复制此句」(建于 0-5 段号锚上)

## Tier 2 · 较大(结构性,排期)

- **★ 读经站通用「记」体系**:段落收藏/划线 + 笔记,key=`corpus:slug:章:段`(slug 全站唯一不撞);每读经站轻量「我的」(续读+收藏+笔记);导出自然带上。
- 「今日一章」钩子横移 9 读经站
- 「关于本站/帮助」页(定位 + 各组铁律 + 数据隐私)
- 跨章/跨书**组内**参引(复用「桥」`qiao` 机制,主要内容工作)
