## 5. 先天方圆图(批次 5)

总览页第三视图「方圆」(matrix/bagong/fangyuan),SVG 单组件 `FangyuanView`。**以下规则表为唯一依据,实现配单测。**

### 5.1 先天卦数(三爻卦)

`xiantianNum(trigramBinary) = 8 - (初爻×4 + 二爻×2 + 三爻×1)`(binary 自下而上,阳=1)
→ 乾1 兑2 离3 震4 巽5 坎6 艮7 坤8。

### 5.2 先天六十四卦次序(邵雍次序)

`xiantianIndex(binary) = 64 - (初×32 + 二×16 + 三×8 + 四×4 + 五×2 + 上×1)`
自检:乾=1,夬=2,大有=3,复=32,姤=33,师=48,坤=64。

### 5.3 圆图布列(上南下北、左东右西)

- 64 槽均分圆周,每槽 5.625°。
- 阳半(次序 1–32,乾…复)居**东半环(左)**:第 n 卦圆心角 = 自正上方(南)起**逆时针**(n−0.5)×5.625°。乾紧贴正上偏东,复紧贴正下偏东。
- 阴半(次序 33–64,姤…坤)居**西半环(右)**:第 n 卦圆心角 = 自正上方起**顺时针**(n−32−0.5)×5.625°。姤紧贴正上偏西,坤紧贴正下偏西。
- 自检:乾姤夹正南(上),复坤夹正北(下);离正东(左)、坎正西(右)附近(离次序 17 居东偏南半槽)。

### 5.4 方图布列(居圆心内)

- 8×8;**行 = 下卦先天数(自下而上 1–8),列 = 上卦先天数(自右向左 1–8)**。
- 自检:乾右下角(1,1),坤左上角(8,8),泰(下乾上坤)右下行左上列=(1,8)左下角…按行列定义:行1列8 = 最下行最左列;否(下坤上乾)=(8,1)最上行最右列;对角线(右下→左上)= 八纯卦。

### 5.5 交互与视觉

- 每卦渲染微缩卦画(6 横线,SVG rect,阳满阴断)+ 悬停显示卦名 tooltip(`<title>` + 高亮描边);点击 navigate 卦页。
- 圆方联动:悬停任一处,圆图与方图同卦同时高亮(朱砂描边)。
- viewBox 正方形自适应,移动端整图缩放可点;桌面悬停、移动点按(单击即跳卦页,tooltip 靠 title)。
- 页脚史料注一行:「伏羲六十四卦方位图,见朱熹《周易本义》卷首,传出邵雍先天之学」(链 /basics/yuanliu#shaoyong)。

### 5.6 单测(engine/xiantian.test.js)

5.1–5.4 的全部自检值 + 圆图角度区间(乾在 (0°, 5.625°] 逆侧、坤在顺侧对称位)+ 64 卦行列/角度无重复。
