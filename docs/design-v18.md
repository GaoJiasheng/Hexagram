## 3. 工序(逐项对标道藏,平台零改)

每书:① `scripts/corpus/<key>.config.mjs` 加书条(源页 + 切片:多篇者逐篇为章/splitHeadings,长书切片防截断);② 原文录入 `src/data/<key>/classics/*`(走 fetch-corpus,**严禁手改**);③ 白话全译 `scripts/authored/<key>-translations.json`(平实直译、一段对一段、歧义取主流注);④ 锚定字词注疏 `src/data/<key>/zhushi-anchored/*`(生僻/人名/制度/术语,≤40 字,无 ref);⑤ 篇/章延伸 `src/data/<key>/yanyi.json`(思想/故事/源流,脱锚 v9 §4 分级);⑥ `texts.json` 含 authorNote 撰人小传;⑦ 薄包装首页(仿 RuHomePage)+ App 路由 + check-data 纳入。**译注延由并发 workflow 产出 + 程序化装配(term 须原文子串、note≤40、段数对齐,违规即弃),同儒佛。**

### 分书风格(开工首批固化)
- **法家**:平实直译;法/术/势、刑名、耕战等术语注疏释之;韩非子寓言(守株待兔、自相矛盾、滥竽充数…)译文存名、注疏点出处;立意取「思想史 + 政治哲学」,如实呈现其严刻,不褒不贬不作现代政治影射。
- **墨家**:逻辑性强,经上下/大取小取近名辩,直译保其论证结构;兼爱/非攻/天志等取主流解;墨家科技(光学/力学/几何)条目注疏点明,不演绎。
- **兵家**:孙子四言韵散,平实直译;形/势/虚实/奇正等兵学概念注疏释之,不演绎现代战例、不作权谋鸡汤。
- **纵横家**:鬼谷子捭阖/反应/内揵等术语玄奥,译文取主流一解、注疏「一说」备异;战国策策论叙事直译,人物/史事注疏。**纵横术不作厚黑/权术教程式发挥,取思想史视角。**
