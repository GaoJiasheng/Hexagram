### 1.2 schema

- 登记表写在 `scripts/fetch-shili.mjs`:`{ id, era, eraGroup, title, source, kind: 'shi'|'yin', page, startMark, endMark, casts: [{ ben, zhi|null, label }] }`。**startMark/endMark 必须取自抓取清洗后的文本**(摘录式抓取:整页抓取→清洗繁转简→按起止标记切片),标记未命中即报错中止,严禁手写原文。
- 人工内容 `scripts/authored/shili.json`:`{ id: { background, translations: [段序数组], reading: [段落数组] } }`,由 fetch-shili 合并。
- 生成物 `src/data/yijing/shili.json`:登记字段 + `paragraphs: [{original, translation}]` + `background` + `reading`。
- check-data:条数 ≥ 19、id 唯一、casts 卦序 1–64、原文非空、覆盖仪表(背景/译文/解读 各 X/总数)。

## 4. 脱锚内容分级规范(硬约束)

筮例背景、史事、人物志含不锚定于抓取原文的事实性叙述,check-data 无法校验,撰写时强制分级:

1. **共识级**(教科书级公认:朱熹著《周易本义》、邵雍北宋人)——直写;
2. **考证级**(有明确学术出处:王亥史事、卦爻辞故事说)——必须随文标注「王国维考」「顾颉刚说」等;
3. **存疑级**(传说、生卒不详、归属有争)——明示「相传」「一说」「不详」;
4. **宁缺毋滥**:把握不足的细节(具体年份、轶事)直接不写;人物小传禁止编造轶闻;筮法分歧(如「之八」诸说)取主流解并注异说。
