## 0. 加一部书的标准工序(平台零改,扩现有组尤其轻)

1. `scripts/corpus/<key>.config.mjs` 加 `BOOKS` 条目(抓取页名 / 切片 splitHeadings|pickHeadings|markPattern / 底本说明)。
2. `src/data/<corpus>/texts.json` 加书目元数据(`slug/title/alias/era/attribution/sections/sectionUnit/brief/authorNote/status`)。
3. `node scripts/fetch-corpus.mjs <key>` 抓原文(繁转简,严禁手改)。
4. `scripts/gen-zhuzi-wf.mjs` 加 BOOKS + 跑 `ONLY=<slug>` → 并发 workflow(译+校双代理,schema 强约束;>55 段大篇自动切片)。
5. `scripts/assemble-newtexts.mjs` 装配译文/注疏/延伸 → `npm run check-data` 过 → commit。
6. **扩现有组:只做 1–5,零平台代码改动**;**开新组**才需 registry 加站 + App 路由 + `[data-site]` 主色 + 首页壳。
7. 铁律延续:佛(研习不宣化)、中医(研习不诊疗)、谋略(伪书批判)、诸子(思想史不作权术教程);新增真书亦守「如实呈现、不下吉凶/疗效/权术断语」。

## 4. 底本与真伪(owner 已定:一律取「流传最广」的通行本)

**原则:每部书一律取流传最广的通行本;真伪/托名/伪古文照旧「照收 + 显著框注其性质」(沿用谋略组体例),不因真伪而排除。**

- **底本一律通行本**:尚书取通行十三经注疏本(含伪古文,框注哪些篇属伪古文);楞严经取通行十卷本(框注真伪有争);冰鉴取通行托名曾国藩本(框注托名)。
- **佛经**:维摩诘 / 阿弥陀 / 遗教等取**鸠摩罗什译本**(流传最广),与现有金刚经罗什本一致;心经已玄奘略本。
- **选篇 vs 全收**:流传最广即足本——**能收足本就收足本**(荀子 32 篇、诗经 305 篇全收);仅礼记 / 管子等过巨者选最通行核心篇,余留后续。
- **谋略组定位**:若收反经 / 清言三书(真书),本组由「伪书批判」扩为「谋略·处世杂纂」,真书 / 伪书分两类框注(伪书 `dubious` 不适用于真书,真书取思想史 / 处世史视角)。
