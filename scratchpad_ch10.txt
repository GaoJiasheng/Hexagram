[0] 今世矩视尺步之辈，与夫守株待兔之流，是不束缚而阱者也。宇宙寥寥，求一豪者，安得哉？家徒四壁，一掷千金，豪之胆；兴酣落笔，泼墨千言，豪之才；我才必用，黄金复来，豪之语。夫豪既不可得，而后世倜傥之士，或以一言一字写其不平，又安与沈沈故纸同为销没乎！集豪第十。
    => 当今那些循规蹈矩、按部就班的人，以及守株待兔一类的人，是不用绳索捆缚而自陷牢笼的人。天地寥廓，要寻一个豪杰之人，哪里能找到呢？家徒四壁却能一掷千金，这是豪杰的胆气；兴致酣畅、下笔如飞、泼墨千言，这是豪杰的才华；“我的才能必定有用，黄金散尽还会再来”，这是豪杰的言语。豪杰之人既然难得，后世那些洒脱不羁之士，便有人用一言一字写出心中的不平，又怎能与那些沉寂无闻的故纸一同湮没呢！集豪第十。
[1] 桃花马上，春衫少年侠气；贝叶斋中，夜衲老去禅心。
    => 骑着桃花马、穿着春衫的少年，意气豪侠；在贝叶经斋中、夜里缝补僧衣的老僧，心归禅寂。
[2] 岳色江声，富煞胸中邱壑；松阴花影，争残局上山河。
    => 山岳的颜色、江河的声响，极大地丰富了胸中的丘壑；松荫与花影之间，争论着残局上的山河胜负。
[3] 骥虽伏枥，足能千里；鹄即垂翅，志在九霄。
    => 良马虽然伏在马槽边，脚力仍能日行千里；天鹅即便垂着翅膀，志向仍在九霄云外。
[4] 个个题诗，写不尽千秋花月；人人作画，描不完大地江山。
    => 个个题诗，写不尽千秋以来的花月；人人作画，描不完大地上的江山。
[5] 慷慨之气，龙泉知我；忧煎之思，毛颖解人。
    => 慷慨激昂的意气，唯有龙泉宝剑懂我；忧愁煎熬的心思，唯有毛笔能替人解开。
[6] 不能用世而故为玩世，只恐遇著真英雄；不能经世而故为欺世，只好对著假豪杰。
    => 不能被世所用便故意玩世不恭，只怕遇上真正的英雄；不能经营世事便故意欺世盗名，那也只配面对假豪杰。
[7] 绿酒但倾，何妨易醉；黄金既散，何论复来。
    => 绿酒只管倾杯而饮，何妨轻易一醉；黄金既已散尽，又何必计较能否复来。
[8] 诗酒兴将残，剩却楼头几明月；登临情不己，平分江上半青山。
    => 诗酒之兴将要阑珊，只剩楼头几轮明月相伴；登高临远之情难以自已，恰与江上的青山各占一半。
[9] 闲行消白日，悬李贺呕字之囊；搔首问青天，携谢朓惊人之句。
    => 闲步而行以消磨白日，悬挂着李贺呕心觅句的诗囊；搔首问天，携带着谢朓惊人的诗句。
[10] 假英雄专吷不鸣之剑，若尔锋铓，遇真人而落胆；穷豪杰惯作无米之炊，此等作用，当大计而扬眉。
    => 假英雄专门吹弄那不响的宝剑，这样的锋芒，一遇真豪杰便要丧胆；穷豪杰惯于做无米之炊，这样的本领，遇上大事时反能扬眉吐气。
[11] 深居远俗，尚愁移山有文；纵饮达旦，犹笑醉乡无记。
    => 深居简出、远离尘俗，尚且愁虑移山之事还留有文字记述；纵情豪饮直到天明，还笑那醉乡竟无人为之作记。
[12] 藜床半穿，管宁真吾师乎；轩冕必顾，华歆洵非友也。
    => 藜草编的床坐穿了一半，管宁真是我的老师啊；见到高官显位必定回头张望，华歆的确不是我的朋友。
[13] 车尘马足之下，露出丑形，深山穷谷之中，剩些真影。
    => 在车马奔驰的尘土之下，露出丑陋的形态；在深山穷谷之中，才留下些许真实的身影。
[14] 吐虹霓之气者，贵挟风霜之色；依日月之光者，毋怀雨露之私。
    => 吐露虹霓般气概的人，可贵在怀有风霜般的严正之色；依附日月光辉的人，不可怀有雨露偏私之心。
[15] 清襟凝远，卷秋江万顷之波；妙笔纵横，挽昆仑一峰之秀。
    => 清澈的襟怀凝聚深远，能卷起秋江万顷的波涛；精妙的笔法纵横挥洒，能挽住昆仑一峰的秀色。
[16] 闻鸡起舞，刘琨其壮士之雄心乎；闻筝起舞，迦叶其开士之素心乎？
    => 听到鸡鸣就起身舞剑，刘琨这是壮士的雄心吧；听到筝声就翩然起舞，迦叶这是开悟之士的素净之心吧？
[17] 友偏天下英杰人士，读尽人间未见之书。
    => 结交遍天下的英杰人士，读尽人间未曾见过的书籍。
[18] 读书倦时须看剑，英发之气不磨；作文苦际可歌诗，郁结之怀随畅。
    => 读书疲倦时须拔剑观赏，英发之气便不会磨灭；作文困苦之际可以放声歌诗，郁结的胸怀便随之舒畅。
[19] 交友须带三分侠气，作人要存一点素心。
    => 交朋友须带三分侠义之气，做人要存一点朴素之心。
[20] 栖守道德者，寂寞一时；依阿权变者，凄凉万古。
    => 栖身固守道德的人，只是一时寂寞；依附逢迎、权诈善变的人，却是万古凄凉。
[21] 深山穷谷，能老经济才猷；绝壑断崖，难隐灵文奇字。
    => 深山穷谷，能使经世济民的才略终老其间；绝壑断崖，却难以隐藏灵秀的文章与奇妙的文字。
[22] 献策金门苦未收，归心日夜水东流。扁舟载得愁千斛，闻说君王不税愁。
    => 在金马门献策却苦于未被采纳，归乡之心日夜如江水东流。一叶扁舟载满千斛愁绪，听说君王不曾对愁绪征税。
[23] 世事不堪评，掩卷神游千古上；尘氛应可却，闭门心在万山中。
    => 世事不堪评说，合上书卷神游于千古之上；尘世的纷扰应当可以摒却，闭门独处而心却在万山之中。
[24] 负心满天地，辜他一片热肠；变态自古今，悬此两只冷眼。
    => 负心之人遍满天地，辜负了他人一片热肠；世态炎凉自古至今变化不定，只凭这两只冷眼旁观。
[25] 龙津一剑，尚作合于风雷。胸中数万甲兵，宁终老于牖下。此中空洞原无物，何止容卿数百人。
    => 龙津的一柄宝剑，尚且能与风雷相合而化去。胸中藏有数万甲兵的谋略，岂肯终老于窗下。这心胸空阔本来无物，何止能容下你们这数百人。
[26] 英雄未转之雄图，假糟邱为霸业；风流不尽之余韵，托花谷为深山。
    => 英雄尚未转移的雄图大略，借酒糟堆成的酒丘来寄托霸业之志；风流未尽的余韵，借花丛山谷来寄托深山之思。
[27] 红润口脂，花蕊乍过微雨；翠匀眉黛，柳条徐拂轻风。
    => 唇脂红润，如花蕊刚经微雨；眉黛匀翠，如柳条徐徐拂过轻风。
[28] 满腹有文难骂鬼，措身无地反忧天。
    => 满腹文章却难以用来骂鬼，自身无处安置反倒担忧起上天来。
[29] 大丈夫居世，生当封侯，死当庙食。不然，闲居可以养志，诗书足以自娱。
    => 大丈夫立身于世，活着应当封侯，死后应当受庙祭享祀。不然的话，闲居也可以修养心志，诗书也足以自我娱悦。
[30] 不恨我不见古人，惟恨古人不见我。
    => 不遗憾我没能见到古人，只遗憾古人没能见到我。
[31] 荣枯得丧，天意安排，浮云过太虚也；用舍行藏，吾心镇定，砥柱在中流乎？
    => 荣枯得失，自有天意安排，如浮云飘过太虚罢了；被任用还是被舍弃、出仕还是隐退，我心自能镇定，岂不像砥柱屹立在江流中央吗？
[32] 曹曾积石为仓以藏书，名曹氏石仓。
    => 曹曾堆积石块建成仓库来收藏书籍，取名叫曹氏石仓。
[33] 丈夫须有远图，眼孔如轮，可怪处堂燕雀；豪杰宁无壮志，风棱似铁，不忧当道豺狼。
    => 大丈夫须有长远的图谋，眼界如车轮般开阔，才怪那栖息堂上的燕雀（目光短浅）；豪杰岂能没有壮志，风骨棱角如铁般刚硬，便不忧惧那当道的豺狼。
[34] 云长香火，千载遍于华夷；坡老姓名，至今口于妇孺。意气精神，不可磨灭。
    => 关云长的香火祭祀，千百年来遍及华夏与四夷；苏东坡的姓名，至今在妇孺之口相传。他们的意气精神，是不可磨灭的。
[35] 据床嗒尔，听豪士之谈锋；把盏惺然，看酒人之醉态。
    => 靠着床榻怡然自失，听豪杰之士的谈锋；端着酒杯半醒半醉，看饮酒人的醉态。
[36] 登高远眺，吊古寻幽，广胸中之邱壑，游物外之文章。
    => 登高远望，凭吊古迹、寻访幽境，开阔胸中的丘壑，神游于物外的文章意境。
[37] 雪霁清境，发于梦想。此间但有荒山大江，修竹古木。
    => 雪后初晴的清幽境界，发端于梦想之中。这里只有荒山大江、修竹古木。
[38] 每饮村酒后，曳杖放脚，不知远近，亦旷然天真。
    => 每次饮过村酒之后，拖着手杖放开脚步，不知走了多远，也是一种旷然天真的意趣。
[39] 须眉之士，在世宁使乡里小儿怒骂，不当使乡里小儿见怜。
    => 须眉男子在世，宁可让乡里的小儿愤怒责骂，也不应让乡里的小儿怜悯。
[40] 胡宗宪读《汉书》，至终军请缨事，乃起拍案曰：「男儿双脚当从此处插入，其它皆狼藉耳！」
    => 胡宗宪读《汉书》，读到终军请缨出使南越之事，便起身拍案说：“男儿的双脚应当从这里踏入，其余的都是些狼藉琐事罢了！”
[41] 宋海翁才高嗜酒，睥睨当世。忽乘醉泛舟海上，仰天大笑，曰：「吾七尺之躯，岂世间凡士所能贮？合以大海葬之耳！」遂按波而入。
    => 宋海翁才华高绝且嗜好饮酒，睥睨当世之人。忽然一次乘醉泛舟海上，仰天大笑说：“我这七尺之躯，岂是世间凡夫俗子所能容纳的？应当用大海来安葬它罢了！”于是按着波涛投身而入。
[42] 王仲祖有好形仪，每览镜自照，曰：「王文开那生宁馨儿？」
    => 王仲祖仪表出众，每次照镜自看，便说：“王文开怎么生出这样美好的儿子？”
[43] 毛澄七岁善属对，诸喜之者赠以金钱，归掷之曰，「吾犹薄苏秦斗大，安事此邓通靡靡！」
    => 毛澄七岁时便擅长对对子，喜爱他的人们赠给他金钱，他回家后掷弃金钱说：“我尚且看轻苏秦那样斗大的富贵，哪里用得着这邓通式的靡靡之财！”
[44] 梁公实荐一士于李于麟，士欲以谢梁，曰：「吾有长生术，不惜为公授。」梁曰：「吾名在天地间，只恐盛著不了，安用长生！」
    => 梁公实向李于麟推荐了一位士人，那士人想要以此感谢梁公实，说：“我有长生之术，愿意毫不吝惜地传授给您。”梁公实说：“我的名声存于天地之间，只怕盛名承载不下，哪里用得着长生！”
[45] 吴正子穷居一室，门环流水，跨木而渡，渡毕即抽之。人问故，笑曰：「土舟浅小，恐不胜富贵人来踏耳！
    => 吴正子穷居一室，门前环绕着流水，靠一根木头渡过，渡过之后便把木头抽走。有人问他缘故，他笑着说：“我这土做的小船浅小，恐怕承受不住富贵人来踩踏罢了！”
[46] 吾有目有足，山川风月，吾所能到，我便是山川风月主人。
    => 我有眼睛有双脚，山川风月只要是我能到达的地方，我便是那山川风月的主人。
[47] 大丈夫当雄飞，安能雌伏？
    => 大丈夫应当雄飞奋起，怎能像雌鸟一样伏藏不动？
[48] 青莲登华山落雁峰，曰：「呼吸之气，想通帝座。恨不携谢朓惊人之句来，搔首问青天耳！」
    => 李白登上华山落雁峰，说：“呼吸的气息，想来能上通天帝的宝座。只恨没有携带谢朓那惊人的诗句前来，只能搔首问青天罢了！”
[49] 志欲枭逆虏，枕戈待旦，常恐祖生，先我著鞭。
    => 志在枭斩叛逆之敌，枕着兵戈等待天明，常常担心祖逖会先于我扬鞭奋起。
[50] 旨言不显，经济多托之工瞽刍荛；高踪不落，英雄常混之渔樵耕牧。
    => 精深的言论不会张扬于外，经世济民的智慧常常藏在工匠、乐师、割草打柴的人中间；高远的行迹不会显露，真正的英雄常常混迹在打渔、砍柴、耕田、放牧的人群里。
[51] 高言成啸虎之风，豪举破涌山之浪。
    => 高远的言论化作虎啸生风之势，豪迈的举动能击破如山涌起的波浪。
[52] 立言者，未必即成千古之业，吾取其有千古之心；好客者，未必即尽四海之交，吾取其有四海之愿。
    => 著书立说的人，未必就能成就流传千古的事业，我看重的是他有千古不朽之心；好客的人，未必就能结交遍天下的朋友，我看重的是他有四海为家之愿。
[53] 管城子无食肉相，世人皮相何为；孔方兄有绝交书，今日盟交安在。
    => 毛笔（管城子）没有富贵的食肉相，世人以貌取人又何必；金钱（孔方兄）从前曾有人写信与它绝交，可如今的结盟订交，那样的操守又在哪里。
[54] 襟怀贵疏朗，不宜太逞豪华；文字要雄奇，不宜故求寂寞。
    => 胸怀贵在疏朗开阔，不宜过分逞弄豪华；文章要雄健奇伟，不宜刻意追求冷僻孤寂。
[55] 悬榻待贤士，岂曰交情已乎；投辖留好宾，不过酒兴而已。
    => 悬榻以待贤士，难道就说这交情已到极致了吗；投辖以留好客，也不过是助酒兴罢了。
[56] 才以气雄，品由心定。
    => 才华因气概而雄健，品格由心地而奠定。
[57] 为文而欲一世之人好，吾悲其为文；为人而欲一世之人好，吾悲其为人。
    => 作文章却想让世上所有人都说好，我为这样的文章感到可悲；做人却想让世上所有人都说好，我为这样的为人感到可悲。
[58] 济笔海则为舟航，骋文囿则为羽翼。
    => 渡越笔墨之海，好文章便是舟船；驰骋文章之苑，好文章便是羽翼。
[59] 胸中无三万卷书，眼中无天下奇山川，未必能文。纵能，亦无豪杰语耳。
    => 胸中没有读过三万卷书，眼中没有见过天下的奇山异水，未必能写出好文章。即使能写，也说不出豪杰之语罢了。
[60] 山厨失斧，断之以剑。客至无枕，解琴自供。盥盆溃散，磬为注洗。盖不暖足，覆之以蓑。
    => 山中厨房没了斧头，就用剑来劈砍。客人来了没有枕头，就拆下琴来当枕头用。洗脸盆破损散架，就用磬盛水来洗漱。被子暖不了脚，就用蓑衣盖上。
[61] 孟宗少游学，其母制十二幅被，以招贤士共卧，庶得闻君子之言。
    => 孟宗年少时外出求学，他的母亲特制了一床十二幅宽的大被，用来招待贤能之士与孟宗同榻而眠，希望他能借此听闻君子的言论。
[62] 张烟雾于海际，耀光景于河渚；乘天梁而皓荡，叩帝阍而延伫。
    => 于海天之际张开烟雾，在河洲之上映耀光景；乘着天梁浩荡而行，叩响天帝的宫门久久伫立等候。
[63] 声誉可尽，江天不可尽；丹青可穷，山色不可穷。
    => 声誉可以穷尽，江天却不可穷尽；丹青可以画尽，山色却画不尽。
[64] 闻秋空鹤唳，令人逸骨仙仙；看海上龙腾，觉我壮心勃勃。
    => 听到秋日长空中鹤唳之声，令人超逸的风骨飘飘欲仙；看到海上蛟龙腾跃，觉得自己豪壮的心志勃然而起。
[65] 明月在天，秋声在树，珠箔卷啸倚高搂；苍苔在地，春酒在壶，玉山颓醉眠芳草。
    => 明月悬在天上，秋声响在树间，卷起珠帘长啸倚立高楼；苍苔铺在地上，春酒斟满酒壶，醉态如玉山颓倒，眠卧在芳草之中。
[66] 胸中自是奇，乘风破浪，平吞万顷苍茫；脚底由来阔，历险穷幽，飞度千寻杳霭。
    => 胸中自有一股奇气，能乘风破浪，平吞万顷苍茫大海；脚下自来宽阔，能历尽艰险、走遍幽深之处，飞越千寻云雾缭绕之地。
[67] 松风涧雨，九霄外声闻环佩，清我吟魂；海市蜃楼，万水中一幅画图，供吾醉眼。
    => 松风涧雨，仿佛九霄云外传来环佩的清响，涤清我吟咏的诗魂；海市蜃楼，恍若万水之中呈现的一幅图画，供我醉眼观赏。
[68] 每从白门归，见江山逶迤，草木苍郁。人常言佳，我觉是别离人肠中一段酸楚气耳。
    => 我每次从白门归来，见江山蜿蜒起伏，草木苍翠茂密。世人常说这景致美好，我却觉得这不过是离别之人肠中一段酸楚之气罢了。
[69] 人每谀余腕中有鬼，余谓鬼自无端入吾腕中，吾腕中未尝有鬼也。人每责余目中无人，余谓人自不屑入吾目中，吾目中未尝无人也。
    => 人们常常谀称我腕中有鬼，我说是鬼自己无端闯入了我的腕中，我的腕中未曾有鬼。人们常常责怪我目中无人，我说是别人自己不屑于进入我的眼中，我的眼中未曾无人。
[70] 天下无不虚之山，惟虚故高而易峻；天下无不实之水，惟实故流而不竭。
    => 天下没有不虚空的山，正因为虚空，所以能高峻；天下没有不充实的水，正因为充实，所以能流淌不竭。
[71] 放不出憎人面孔，落在酒杯：丢不下怜世心肠，寄之诗句。
    => 摆不出憎恶世人的面孔，便寄托在酒杯之中；丢不下怜悯世人的心肠，便寄托在诗句之中。
[72] 春到十千美酒，为花洗妆；夜来一片名香，与月熏魄。
    => 春天到来，斟上价值十千的美酒，为花儿洗妆；夜色降临，燃起一片名贵香料，为明月熏魂。
[73] 忍到熟处则忧患消，谈到真时则天地赘。
    => 忍耐到纯熟之处，忧患自然消散；谈论到透彻真切之时，连天地都显得多余。
[74] 醺醺熟读《离骚》，孝伯外敢曰并皆名士；碌碌常承色笑，阿奴辈果然尽是佳儿。
    => 醉醺醺地熟读《离骚》，除了王孝伯，还有谁敢说自己也是名士；庸庸碌碌只知承欢献媚，那些阿奴辈倒果然都成了佳儿。
[75] 剑雄万敌，笔扫千军。
    => 剑气可雄视万敌，笔锋能扫荡千军。
[76] 飞禽铩翮，犹爱惜乎羽毛；志士捐生，终不忘乎老骥。
    => 飞鸟即便羽翼受损，仍爱惜自己的羽毛；志士纵然捐躯赴死，终究不忘老骥伏枥之志。
[77] 敢于世上放开眼，不向人间浪皱眉。
    => 敢于在世上放开眼界，不向人间轻易皱眉。
[78] 缥缈孤鸿，影来窗际，开户从之，明月入怀，花枝零乱，朗吟枫落，吴江之句，令人凄绝。
    => 缥缈的孤鸿，身影映上窗边，推门追随而去，明月便映入怀中，花枝错落纷披，朗声吟诵着枫落吴江的诗句，令人凄绝。
[79] 云破月窥花好处，夜深花睡月明中。
    => 云破处，月光窥见繁花绽放的好处；夜深时，花儿沉睡在月光之中。
[80] 三春花鸟犹堪赏，千古文章只自知。文章自是堪千古，花鸟三春只几时。
    => 三春的花鸟尚且值得欣赏，千古流传的文章却只有自己知晓其中甘苦。文章本自能流传千古，花鸟不过三春光景能有几时。
[81] 士大夫胸中无三斗墨，何以运管城？然恐酝酿宿陈，出之无光泽耳。
    => 士大夫胸中若没有三斗墨水般的学问，凭什么挥动手中的笔？然而又担心积存已久、酝酿陈腐，写出来的文字反而没有光泽。
[82] 攫金于市者，见金而不见人；剖身藏珠者，爱珠而忘自爱。与夫决性命以饕富贵，纵嗜欲以损生者何异？
    => 在闹市中攫取金子的人，只看见金子却看不见旁人；剖开身体藏匿珍珠的人，爱惜珍珠却忘了爱惜自己。这与那些拼死拼活去贪求富贵、放纵嗜欲以损害生命的人，又有什么不同呢？
[83] 说不尽山水好景，但付沈吟；当不起世态炎凉，惟有闭户。
    => 说不尽山水间的美景，只能付诸沉吟；经受不住世态的炎凉冷暖，唯有闭门自守。
[84] 杀得人者，方能生人。有恩者，必然有怨。若使不阴不阳，随世披靡，肉菩萨出世，于世何补？此生何用？
    => 能杀伐决断的人，才能真正成全人。有恩德之人，必然也会招来怨恨。若是不阴不阳、随波逐流一味顺从世俗，如同泥塑的活菩萨出世，对这世间又有什么补益？这一生又有何用？
[85] 李太白云：“天生我才必有用，黄金散尽还复来。”杜少陵云：“一生性僻耽佳句，语不惊人死不休。”豪杰不可不解此语。
    => 李太白说：上天生我之才必有用处，黄金散尽还会再来。杜少陵说：一生性情僻好，沉溺于锤炼佳句，语不惊人誓不罢休。真正的豪杰不可不懂得这番话。
[86] 天下固有父兄不能囿之豪杰，必无师友不可化之愚蒙。谐友于天伦之外，元章呼石为兄；奔走于世途之中，庄生喻尘以马。
    => 天下固然有父兄也不能约束住的豪杰，却必定没有师友教化不了的愚昧蒙昧之人。在天伦之外结交朋友，米元章曾呼顽石为兄；在世途之中奔走求索，庄子曾以奔马比喻尘埃。
